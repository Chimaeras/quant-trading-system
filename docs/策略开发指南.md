# 策略开发指南

## 一、策略基类

所有策略需继承 `BaseStrategy`，实现 `on_bar` 和 `on_tick` 方法。

```python
from strategies.base_strategy import BaseStrategy
from typing import Dict, Optional

class MyStrategy(BaseStrategy):
    def __init__(self):
        super().__init__('MyStrategy', {'param1': 10})

    def on_bar(self, bar: Dict) -> Optional[str]:
        """
        每根 K 线触发
        bar 包含: open, high, low, close, volume
        返回: 'buy' | 'sell' | 'hold' | None
        """
        # 你的逻辑
        return 'hold'

    def on_tick(self, tick: Dict) -> None:
        """每个 tick 触发（可选）"""
        pass
```

## 二、扩展步骤

1. 在 `modules/compute-python/strategies/` 下新建 `my_strategy.py`
2. 继承 `BaseStrategy`，实现上述方法
3. 在 `strategies/__init__.py` 中导出新策略
4. 系统自动发现并加载

## 三、内置策略说明

### 3.1 均线交叉 (MA_Cross)

- 短周期上穿长周期 → 买入
- 短周期下穿长周期 → 卖出
- 参数: `short_period`, `long_period`

### 3.2 布林带 (BOLL)

- 价格触及下轨 → 买入
- 价格触及上轨 → 卖出
- 参数: `period`, `std_dev`

### 3.3 MACD

- MACD 金叉 → 买入
- MACD 死叉 → 卖出
- 参数: `fast`, `slow`, `signal`

## 四、回测

```python
from strategies import MACrossStrategy
from engines import BacktestEngine, DataEngine

data_engine = DataEngine()
data = data_engine.load_csv('000001')

strategy = MACrossStrategy(short_period=5, long_period=20)
engine = BacktestEngine(initial_cash=1000000)
result = engine.run(strategy, data)
print(result)
```

## 五、注意事项

- 策略需保持无状态或仅维护必要状态
- 注意 `bar` 的列名可能是 `close` 或 `Close`，需兼容
- 实盘前务必充分回测
