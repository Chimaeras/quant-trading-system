# 开发规范

## 一、后端 (Java Spring Boot)

### 1.1 代码结构

```
controller/   - REST 控制器，仅做参数校验和调用 service
service/      - 业务逻辑
repository/   - 数据访问
entity/       - JPA 实体
dto/          - 请求/响应对象
config/       - 配置类
security/     - 安全相关
```

### 1.2 规范

- 使用 Lombok 减少样板代码
- Controller 返回 `ApiResponse<T>` 统一格式
- 异常通过 `GlobalExceptionHandler` 处理
- 日志使用 `@Slf4j`，关键操作记录 INFO
- RESTful 风格：GET 查询、POST 创建、PUT 更新、DELETE 删除

### 1.3 配置

- 敏感配置使用环境变量
- 多环境：`application.yml` + `application-{profile}.yml`

## 二、前端 (Vue3)

### 2.1 代码结构

```
views/        - 页面组件
components/   - 可复用组件
api/          - 接口封装
store/        - Pinia 状态
router/       - 路由
```

### 2.2 规范

- 使用 Composition API + `<script setup>`
- API 调用集中在 `api/` 目录
- 使用 Element Plus 组件库
- 路由懒加载：`() => import('@/views/xxx.vue')`

## 三、量化引擎 (Python)

### 3.1 代码结构

```
strategies/   - 策略
engines/      - 回测、数据、信号、风控引擎
utils/        - 工具函数
```

### 3.2 规范

- 策略继承 `BaseStrategy`
- 类型注解：使用 `typing`
- 文档字符串：模块和公共方法需注释
- 依赖版本固定在 `requirements.txt`

## 四、Git 提交

- feat: 新功能
- fix: 修复
- docs: 文档
- refactor: 重构
- style: 格式

示例：`feat: 添加 MACD 策略`
