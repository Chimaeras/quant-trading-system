## §1 本轮怎么做的

### 1.1 判据来源（只借判据，不采纳其结论）

Harvey–Liu–Zhu 的核心贡献是「多重检验下 t 门槛应上移」（`t > 3.0` 一类）。本轮**不使用**这个数值结论——
它属于冻结口径「`rule_score` 是 0–100 截面百分位，不是上涨概率」之外的**另一套**叙述，且 A6 轴只做
**登记**（`REGISTERED_ONLY`），**禁止**任何「因子是否显著」的叙述（预注册 §9.7）。

本轮从该文借用的判据是**结构性**的两条：

1. **不确定性必须与估计量同名同源**——报告标准误/置信区间时，必须能指认它们是**哪一个**估计量的、
   在**哪一种**依赖假设下成立的；名字与算法不一致本身就是缺陷（本轮 A1b / A3d / A4b / A8a）。
2. **定义失效时必须显式标记，而不是输出实数**——当样本量不足以形成该估计量时，
   不得输出一个「看起来像估计值」的数（本轮 A2a / A2b / A2d）。

### 1.2 判据的三档强度（L / A / P）

| 档 | 含义 | 本轮用途 |
|---|---|---|
| **L** | 文献**明示** | 只支持「做法种类」（要报告与估计量同名同源的不确定性），**不支持**具体规范（如 HAC 滞后阶、bootstrap 块长、覆盖率阈值） |
| **A** | **算术推导** | A1a/A3b/A5a/A5b/A6b 的不变式：`ci = mean ± 1.96·hac_std`、`prod == cbrt-lag Bartlett`、`std_ratio ≈ 1/√T` 等 |
| **P** | **项目自建** | A2c/A3c/A5c 的阈值（5% 钳位率、0.90 比率、0.85 覆盖率）——**是本轮自设的量级线，不是文献论断** |

**这一点必须写清**：R007 的 L 档**不足以**支撑任何具体数值门槛。因此凡是带阈值的断言（A2c / A3c / A5c），
报告的写法一律是「在**我自设的**量级线下，实测为 X」，不是「违反了文献规范」。

### 1.3 执行方式（防掩码）

### 1.4 与 R006 的两处 harness 差异（诚实披露，见附录 A）

1. **金丝雀 harness 是 `normalized-pair` 模式**：R006 的 CLN/INJ 通过改写**输入文本**实现；
   R007 的部分检查器读的是**结构化中间量**（如 `ci_is_zero_width` 这类 int 载荷、`matched_bs` 这类字符串），
   故 op 语言扩展为 `probe_set / probe_map / probe_copy / text_set / text_restore / text_copy / multi`。
   **语义等价**（都在同一检查器上做「取值同源 ⟹ 失效」与「注入违规 ⟹ 触发」的对照），但**实现机制不同**，
   两轮的金丝雀 PASS **不可直接互比**。
2. **探针键名 `sentinel_nw_perm_control` 实际实现的是 lag = 2 对照**，不是置换对照（键名有误导性）。
   n=10 时 cbrt 规则的滞后恰为 `floor(10^(1/3)) = 2`，故生产值与它**相等才是预期**；
   该量**不在 K9 门内**，不影响任何判定。已在 `result.json` 中按实测改名
   （`sentinel_nw_lag2_control_probe_key_perm`）并写入 `sentinel_note`。

### 2.1 三条 K1/K3 级断言的证据细节（本轮判定的承重部分）

**A2a（K1）——零宽区间与真实点估计并存。**
输入：1 个信号日、当日 10 只股票。实测 `cross_section_days=1`、`total_observations=10`、
`rank_ic_mean = −0.9878787878787879`（**真实点估计**，来自 `summarize`），
而 `hac_std = 0.0`、`ci = [0.0, 0.0]`（`ci_is_zero_width=1`、`ci_contains_mean=0`、`mean_is_nonzero=1`）。
该 `block` 共 19 键，**含** `note` 键，但 `note` 由 `totalObservations()==0` 守卫（`:550-551`），
本情形不触发；`status` 键**只**出现在 `unavailableScopeBlock`（`:560`），本路径不经过它
（`snapshot_has_status_key=false`）。
载荷层同样成立：`:544-546` 对该三键套 `round4(v)=Math.round(v*10000.0)/10000.0`，`0.0 → 0.0`。
`engine_record_field_names` 显示记录类型本身也没有「退化」字段。
⟹ **一个真实的点估计与一个零宽的 95% 区间并列出现在同一块、同一 HTTP 响应里，且没有任何字段说明区间已失效。**

**A5c（K3）——名义 95% 区间的实测覆盖率。**
80 个单元（n ∈ {5,10,17,27} × h ∈ {1,2,3,5,10} × 5 个 DGP）× 2 臂，每单元 1000 次重复。
触发判据为**双重**：实测覆盖率 < 0.85 **且** Clopper–Pearson 单侧 99% 下界 < 0.85
（等价变形：`L < 0.85 ⟺ P(X ≥ k | p=0.85) > 0.01`；冻结文本已披露该规则在 reps=1000 下近似等价于「覆盖率 ≲ 87%」）。

- 触发格数：**BOOT 62/80、HAC 60/80、任一臂 66/80**；
- `min boot = 0.344`（n=5/h=5/`MA_equal_hm1`）、`min hac = 0.392`（同一格）、`max boot = 0.933`；
- 全部 80 格的 `zero_width = 0`、`se_zero = 0` ⟹ 这一条**不是**退化导致的，是**依赖结构**导致的；
- 按 DGP 平均覆盖率（boot / hac）：`IID 0.848/0.855`、`AR1_0.2 0.794/0.816`、`AR1_0.5 0.670/0.719`、
  `AR1_0.7 0.536/0.594`、`MA_equal_hm1 0.734/0.748`。

**必须与 A2c 分开读**：A2c 证明 `Math.max(hacVar/n, 0)` 这条**钳位**在本网格里**几乎不可达**（0/20000），
所以 A5c 的覆盖率不足**不能**归因于钳位——它来自「HAC 窗口只由 n 决定、与 h 解耦」这一条（A3a/A3c/A3d），
以及 bootstrap 块长被钳到 `floor(√n)`（A4a/A4b）。四条断言在机制上互相支撑。

### 4.1 被证伪的两条，逐条说明

**P-5 被证伪（钳位不是可达的退化机制）。** 我此前的算术直觉是「`Math.max(hacVar/n, 0)` 在 n=5 时

**A-3 A3c 统计量的口径。**

**A-4 A5a 的容差自评。**

⟹ 「既有测试通过」与「我的相对判据判 VIOLATED」**不矛盾**，因为两者不是同一个判据。
**我的 5% 相对容差不是这个不变式的固有容差**，属 P 档自设；这一点必须在读 A5a 时被记住。

**A-9 post-hoc 观察（`round4` 与伪零宽区间）。**
`round4(v) = Math.round(v * 10000.0) / 10000.0`：`NaN → 0.0`；`±Inf → 9.223372036854776E14`；
当 `1.96·hac_std < 5e-5`（即 `hac_std < 2.55e-5`）时，`[mean − 1.96·se, mean + 1.96·se]`
在 4 位小数下可**塌成零宽**（`ci_lower == ci_upper`）而 `mean` 非零。
**这是 post-hoc 发现，不在预注册的 21 断言内，不参与总判定合成**，已登记为 `D-R007-09`。
它与 A2a **是同族但不同因**（A2a 是 `n<2` 导致 se=0，本项是**显示精度**导致塌缩）。
