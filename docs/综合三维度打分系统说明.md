# 综合三维度打分系统说明

## 概述

本系统根据《打分机制》文档实现了完整的三维度100分制股票打分机制，旨在通过多维度分析评估股票在未来2-5天的升值概率。

## 打分维度

### 一、技术分析维度 (30分)

技术分析关注股票价格走势、成交量变化和短期技术指标，是判断短期走势最直接的依据。

#### 1. 均线排列 (10分)

| 状态 | 得分 | 说明 |
|------|------|------|
| 多头排列 | 10 | 5日均线>10日均线>20日均线>60日均线，且呈向上趋势 |
| 弱势多头 | 7 | 均线排列向上但趋势不够强 |
| 中性排列 | 5 | 均线方向不明显或短期有交叉 |
| 空头排列 | 2 | 5日均线<10日均线<20日均线<60日均线，且呈向下趋势 |

#### 2. RSI指标 (10分)

| 状态 | 得分 | 说明 |
|------|------|------|
| 超卖 (RSI<30) | 10 | 可能迎来反弹 |
| RSI 30-40 | 8 | 相对低位 |
| RSI 40-60 | 7 | 中性区域 |
| RSI 60-70 | 5 | 偏高 |
| 超买 (RSI>70) | 3 | 可能面临回调 |

#### 3. MACD指标 (10分)

| 状态 | 得分 | 说明 |
|------|------|------|
| 零轴上金叉 | 10 | DIF线从下向上突破DEA线，且在零轴上方 |
| 金叉 | 8 | DIF线从下向上突破DEA线 |
| 多头 | 6 | DIF和DEA都在零轴上方 |
| 中性 | 5 | 无明显信号 |
| 空头 | 3 | DIF和DEA都在零轴下方 |
| 死叉 | 2 | DIF线从上向下突破DEA线 |
| 零轴下死叉 | 0 | DIF线从上向下突破DEA线，且在零轴下方 |

### 二、基本面分析维度 (40分)

基本面分析关注公司的财务状况、估值水平和盈利能力，是判断股票内在价值的基础。

#### 1. 估值水平 (15分)

基于PE（市盈率）和PB（市净率）评估：

| 估值状态 | 得分 | 条件 |
|----------|------|------|
| 低估值 | 12-15 | PE<15 或 PB<1 |
| 中等估值 | 8-11 | PE在15-30之间 |
| 高估值 | 3-6 | PE>40 或 PB>3 |

#### 2. 盈利能力 (15分)

基于ROE（净资产收益率）评估：

| 盈利状态 | 得分 | ROE范围 |
|----------|------|---------|
| 优秀 | 12-15 | ROE>20% |
| 良好 | 9-11 | ROE 15%-20% |
| 一般 | 6-8 | ROE 10%-15% |
| 较差 | 3-5 | ROE<10% |

#### 3. 财务健康度 (10分)

基于资产负债率和流动比率评估：

| 健康状态 | 得分 | 条件 |
|----------|------|------|
| 健康 | 8-10 | 资产负债率<50%，流动比率>1.5 |
| 中等 | 5-7 | 资产负债率50%-70%，流动比率1.0-1.5 |
| 潜在风险 | 2-4 | 资产负债率>70%或流动比率<1.0 |

### 三、市场情绪分析维度 (30分)

市场情绪分析关注投资者对股票的情绪和态度，是判断短期市场反应的重要参考。

#### 1. 新闻舆情 (15分)

基于技术指标和市场行为推导：

| 状态 | 得分 | 说明 |
|------|------|------|
| 强烈正面 | 12-15 | 价格上涨放量，技术面强势 |
| 中性偏正 | 8-11 | 价格稳定或小幅上涨 |
| 中性 | 5-7 | 价格波动不大 |
| 负面 | 2-4 | 价格下跌或技术面弱势 |

#### 2. 社交媒体讨论热度 (8分)

基于成交量比率作为代理指标：

| 状态 | 得分 | 说明 |
|------|------|------|
| 高热度积极 | 7-8 | 成交量大幅放大且价格上涨 |
| 中等热度 | 4-6 | 成交量接近均值 |
| 低热度 | 2-3 | 成交量萎缩 |

#### 3. 机构观点 (7分)

基于技术面和基本面推导：

| 状态 | 得分 | 说明 |
|------|------|------|
| 积极 | 5-7 | 技术面和基本面双优 |
| 中性 | 3-4 | 表现一般 |
| 消极 | 1-2 | 技术面或基本面较弱 |

## 动态权重分配

系统根据市场环境和股票特性动态调整各维度权重：

### 市场环境权重

| 环境 | 技术面 | 基本面 | 情绪面 |
|------|--------|--------|--------|
| 牛市 | 30% | 50% | 20% |
| 熊市 | 40% | 30% | 30% |
| 震荡市 | 40% | 20% | 40% |

### 股票特性权重

| 类型 | 技术面 | 基本面 | 情绪面 |
|------|--------|--------|--------|
| 价值股 | 30% | 50% | 20% |
| 成长股 | 35% | 45% | 20% |
| 周期股 | 40% | 30% | 30% |
| 防御股 | 25% | 40% | 35% |

## 投资建议规则

| 综合得分 | 建议 | 说明 |
|----------|------|------|
| ≥85分 | 强烈买入 | 综合表现极佳，适合积极布局 |
| 70-84分 | 买入 | 综合表现良好，可逐步建仓 |
| 55-69分 | 持有 | 表现一般，建议观望 |
| 30-54分 | 观望 | 表现较弱，谨慎操作 |
| <30分 | 强烈卖出 | 存在较大风险，及时止损 |

## 行业适配修正

不同行业有不同的调整系数：

| 行业 | 调整分 |
|------|--------|
| 银行 | +5.0 |
| 新能源 | +4.0 |
| 科技、保险 | +3.0 |
| 房地产 | -2.0 |

## API接口

### 综合打分

```http
POST /api/scoring/comprehensive/run
Content-Type: application/json

{
  "tradeDate": "2026-04-17",  // 可选，默认最新交易日
  "persist": true,             // 可选，默认true
  "includeItems": false,       // 可选，默认false
  "lookbackDays": 520          // 可选，默认520
}
```

### 趋势打分

```http
POST /api/scoring/trend/run
Content-Type: application/json

{
  "tradeDate": "2026-04-17",
  "biasThreshold": 5.0,
  "persist": true
}
```

## 注意事项

1. **情绪数据来源**：当前版本基于技术指标和市场行为推导情绪分数，未接入真实舆情API。后续可集成同花顺舆情API、雪球讨论量API等外部数据源。

2. **基本面数据**：当前使用PE、PB等有限指标。完整版应包含ROE趋势、净利润率、毛利率、营收增长率、Z-score等财务指标。

3. **机构观点**：当前为推导值。完整版应接入券商研报评级数据。

4. **风险控制**：当综合得分<60分且财务健康度<6分时，系统会给出风险提示。
