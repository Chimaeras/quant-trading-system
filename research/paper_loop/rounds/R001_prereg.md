## 2. 假设

- **H0（零假设）**：在本地 A 股样本（2024-01-02 – 2026-09-07）与项目冻结口径（T+1、次日开盘入场、T+2/T+3 持有、扣万三/万五/单边万二）下，过去 N 日收益与未来净收益**不存在负向关系**：截面 rank IC ≥ 0，或虽为负但不显著（HAC t > −2.0）。
- **H1（备择假设，即论文主张的本地化版本）**：过去 N 日收益**负向**预测未来净收益（"past losers outperform past winners"），且在扣成本后仍存在可实现的**长多**价值：过去输家分位（D1）的扣费净收益显著高于过去赢家分位（D10）与全池均值。
- 一句话可证伪表述：**若把 A 股可交易池按过去 20 日收益分成十组，则最低分位组在 T+3 口径下的扣费净收益不高于最高分位组。**

> 范围限定：本轮**只测反转腿**。论文的规模（剔除最小 30% 壳污染）与 EP 价值腿**不立项**——所需数据（市值、盈余）本地缺失，见 `blocked_queue.md` B-R001-02。

## 3. 可证伪预测

> 格式：「若 H1 成立，则在 X 上应观察到 Y」。

- **预测 P1**：在 IS 窗口（2024-01-02 – 2025-12-31），`past_ret_20` 与 T+3 扣费净收益的**日度截面 Spearman rank IC 均值 < 0**，且 HAC(Newey-West, lag=25) t 统计量 **≤ −2.0**。
- **预测 P2**：十分位组合的**扣费净收益单调递减**（D1 > D2 > … > D10，允许噪声），且 D1 − D10 净价差 > 0。
- **预测 P3**：D1 组合的扣费净收益 > 全池等权扣费净收益（长多可实现）。
- **预测 P4**：上述结论在 2026 年 OOS 窗口**符号一致**。
- **H0 下的期望**：IC 均值在 0 附近随机波动，|t| < 2；D1 与 D10 无稳定高低关系；D1−D10 净价差在 0 附近。

## 5. 数据与样本

- **数据源**：本地 MySQL `quant_db.market_data`（前复权，2,455,536 行）+ `stock_info`（5,835 行，仅当前快照）
- **数据区间（唯一真实可用面板）**：**2024-01-02 → 2026-09-07**，645 个交易日，日均截面 3,790 只，最小截面 3,267 只
  - 本地 `market_data` 声称覆盖 2003-12-16 起，但 2003–2019 年**每年只有 1 只股票**、2020–2023 年**每年只有 2 只**（实测），**不构成横截面面板**。此为关键发现，见第 11 节。
  - 交易日历（`market_data` 去重去交易日反推）用作权威；`trading_calendar` 表仅覆盖 2024-08-19 – 2026-08-19（485 天），差异须披露。
- **数据清洗（预注册，不得事后修改）**：
  - 重复主键：`(stock_code, trade_date)` 重复 **22,945 行**（占 0.93%）。处理：**保留 `id` 最大的一行**，其余丢弃。丢弃行数须写入报告。
  - 非正价/非正量行：`close_price≤0` 757 行、`open_price≤0` 758 行、无 `pre_close` 755 行 → 从可交易池剔除并计数。
- **股票池定义**（沿用项目 `ScoringUtils` 语义）：
  - 剔除 `close≤0` / `volume≤0`；
  - 上市时长闸：`stock_info.list_date` 起 ≥ 60 个自然交易日（`list_date` 属不随时间修订的事实，可安全使用）；缺失时回退到 `market_data` 首个 bar；
  - **ST 闸无法实现**：本地无历史名称，`stock_info` 为当前快照（非 PIT），用当前 ST 状态过滤历史会造成前视 → **主配置不启用 ST 过滤并披露**，另做一项"用当前名称含 ST 剔除"的**污染型敏感性**（仅作披露，不参与判定）；
  - 流动性闸：主配置不加绝对阈值（本地 `minAvgAmount` 单位存在歧义）；稳健性变体使用**当日截面 amount 中位数**作为相对闸。
- **PIT 可用性说明**：信号全部来自 `market_data` 中 `trade_date ≤ signal_date` 的行；`pre_close` 用于涨跌停判定，与前复权序列自洽。
- **已知偏差披露（`研究口径规范.md` 第 5 节，必须写进报告）**：
  1. **前复权**：`market_price_raw` 与 `adjust_factor` 均为 0 行，只能使用前复权序列。收益比值方向正确，但**执行价并非当时可成交的真实价格**；这是对项目"执行价必须用不复权价"口径的**偏离**，必须显式披露。
  2. **`stock_info` 非 PIT**：`security_master_history` 为 0 行 → 历史池用当前快照回填，**已退市/已更名股票完全缺失**（status 全部 = 1，无退市样本）→ **幸存者偏差，且对本假设方向是"放大毛收益"**（反转偏好高波动小票，退市股缺失会抬高输家组表现）。
  3. **`selector_result` 稀疏**：仅 17 个交易日 → **无法用生产 `rule_score` 做同口径基线**，本轮 baseline 改用同口径等权池与分位腿（见第 8 节），并记 `blocked_queue.md` B-R001-03。

## 6. 成本与口径（必须内建，复用 `ResearchConvention`，不硬编码）

- 买入佣金：`0.0003`（万三）
- 卖出印花税：`0.0005`（万五）
- 单边滑点：`0.0002`（万二）
- 入场假设：`signal_date` 下一交易日**开盘**（`ENTRY_ASSUMPTION_DEFAULT`）
- 退出假设：入场后第 h 个持有交易日**收盘**，h ∈ {2, 3}（`LABEL_HORIZONS`）
- 净收益公式（与 `研究口径规范.md` §2 一致，不得改写）：
  `net = exit_price×(1 − sell_tax − slippage) / (entry_price×(1 + commission + slippage)) − 1`
- 成交状态处理（`ResearchConvention` 状态码，**不得删除样本**）：
  - `NOT_BUYABLE`：`entry_date` 开盘价 ≥ 当日涨停价（按板块：主板 10%、创业板/科创板 20%、北交所 30%）
  - `SUSPENDED`：`signal_date`/`entry_date`/`exit_date` 任一 volume ≤ 0
  - `NOT_SELLABLE`：`exit_date` 收盘价 ≤ 当日跌停价
  - `DELISTED`：本地不可识别（无退市样本）→ 计数恒为 0，须在报告披露
  - `FILLED`：以上皆非
  - 净收益只在 `FILLED` 样本上统计（与生产 `ScoringBacktestService` 的 `metricScope=FILLED_SAMPLE` 一致），但**全部分位组合的成交漏斗必须报告**
- 输出类型：**rank IC 与分位净收益，不是概率**。本轮**不产生** `rule_score`，也不得把任何输出表述为上涨概率。

## 7. 切分方案

- **IS-A（探索）**：2024-01-02 → 2024-12-31（242 个交易日）
- **IS-B（确认）**：2025-01-01 → 2025-12-31（243 个交易日）
- **OOS（锁定留出）**：**2026-01-01 → 2026-09-07**（160 个交易日）——**在参数与阈值锁定前不得运行**
- 方法：**严格时间顺序切分**，不随机打乱；不 shuffle；不做随机 K 折。
- 重叠处理：h=3 时信号→退出跨度最多 6 个交易日，日度 IC 序列高度重叠 → 主统计量使用 **Newey-West HAC 标准误（lag = N + h + 2）**，并额外报告**去重叠子样本**（每隔 `N+h+2` 个交易日取 1 个信号日）的结果。
- 多重检验披露：统计量不用于"择优"，判定只看预注册的**主配置 N=20, h=3**。
- 随机种子：不涉及随机过程；若实现中出现任何随机（bootstrap），种子固定 `20260914`。

## 8. 验收阈值（扣除成本后）

> 不得直接抄用论文原始数字（论文未提供反转腿的表格与 t 值）。

- **主配置**：`N=20`（过去 20 个交易日收益），`h=3`（T+3 口径）
- **主阈值（IS-A + IS-B 合并）**：
  1. 日度截面 rank IC 均值 **< 0**
  2. HAC(lag=25) t 统计量 **≤ −2.0**
  3. D1 分位**扣费**净收益 > D10 分位扣费净收益
  4. D1 分位扣费净收益 > 全池等权扣费净收益
- **对照基线（同口径、含成本）**：
  - `B0` 全池等权扣费净收益（T+3，次日开盘入场）
  - `B1` `D10`（过去赢家分位）扣费净收益
  - `B2` 市场参照：`index_quote` 中证1000（000852）/ 沪深300（000300）同区间买入持有净收益（仅 2024-08-12 起可用，须披露区间差异）
  - `B3` **生产 `rule_score` 基线本轮不可得**（`selector_result` 仅 17 天）→ 记 `blocked_queue.md` B-R001-03，**不得用替代物冒充**
- 通过标准：第 2 节 H1 成立 且 主阈值 1–4 全部满足 **且** 第 9 节杀死条件均未触发。

## 9. 杀死条件（**不得事后放宽**）

> 出现以下任一结果即判定 H1 不成立，停止本轮并归档。

1. **K1 方向不成立**：IS-A+IS-B 上 `past_ret_20` 与 T+3 净收益的 rank IC 均值 **≥ 0**，或 HAC t **> −2.0** → REJECTED。
2. **K2 成本高于收益**：毛收益（未扣费）D1−D10 价差 > 0，但**扣费后** D1−D10 价差 ≤ 0 → REJECTED，失败分类「成本高于收益」。
3. **K3 长多不可实现**：D1 分位扣费净收益 ≤ 0，或 ≤ 全池等权扣费净收益 → REJECTED（即使多空价差为正也不采纳）。
4. **K4 样本外衰减**：2026 OOS 上 IC 均值**符号翻转**（≥ 0）→ REJECTED，分类「样本外衰减」；符号一致但 HAC t > −2.0 → 状态记 **INCONCLUSIVE**，不得 ADOPTED。
5. **K5 与现有因子重复**：反转仅在 `N=1` 上显著（t ≤ −2.0），而 `N=5`、`N=20` 上均不显著 → 归类「与现有因子重复」（生产引擎 `CodexShortCycleScoringEngine` 已对 `er1` 赋负权重 −0.15）→ 不得作为新发现，状态记 REJECTED。
6. **K6 参数敏感**：在 `N∈{16,24}`（±20%）且 `h∈{2,3}` 的组合中，**少于 3 组**复现出「IC<0 且 HAC t ≤ −2.0」→ REJECTED。
7. **K7 工具有效性（控制实验）**：必须包含一个**故意泄漏**的对照（用 `entry_date` 当日开盘信息构造信号）。若该对照**未能**产出明显更强、方向更极端的结果，则判定实验工具有缺陷 → 本轮记 **INCONCLUSIVE**，且**不得**把主结果作为任何证据使用。
8. **K8 去重叠后消失**：去重叠子样本上 IC 均值 ≥ 0 → REJECTED（说明结论由重叠样本伪重复制造）。

以下任一情形触发即整轮 REJECTED（负知识）但仍需归档：任一杀死条件被触发即终止本轮，不得通过增改样本区间/换持有期/换窗口来"抢救"。
