# 阶段1：逐因子全截面 Rank IC 诊断报告（2025-10-13 ~ 2026-08-31）

> 前置：阶段0 打通了全截面落库（V32/V33），使 **Rank IC 首次可算**。
> 此前只能算 Top-N 内部 IC，而那里 IC ≈ 0 且无意义。
>
> **一句话结论：因子库不是"没信息"，而是"方向反了"。**
> 动量/趋势族因子在全截面上有**统计显著的负 IC**，而策略给它们**正权重**。
> 风险族因子方向正确。

---

## 1. 方法与口径

| 项 | 口径 |
|---|---|
| 数据 | `factor_cross_section_score.factor_percentiles`（V33 新增） |
| 截面日 | **33 天抽样**：每月末 2 个交易日 + 每月首个交易日 |
| 入场 | 信号日 t 的**下一交易日开盘价**（与既有回测一致，无未来函数） |
| 出场 | t+k 收盘，k ∈ {1,3,5,10,20} |
| 价格 | `market_data` **前复权** |
| IC | 截面日内，因子百分位与前向收益的 Spearman 相关 |
| 显著性 | 对 **IC 日序列**做 Newey-West（滞后 = k−1），**不**把股票-日混算 |
| 逐因子样本 | **全部带百分位的行**（含 eligible=false），避免用策略闸门筛因子样本 |

**必须披露的两处偏乐观**：
1. 截面日为**抽样**而非逐日，IC 序列在月内聚集。NW 只修正自相关、
   不修正该聚集，故 **t 值应视为上界**。
2. 33 个截面日的样本量下，IC 均值本身的标准误约 0.035（IC 标准差 0.20 / √33）。

### 2.1 一个反直觉的细节：IC 为负，但 D1 组收益最差、D10 组不是最低

**IC 为负（分数越高收益越低）与"D1 组表现最好"是一致的**——
D1 是**分数最低**组。所以两者不矛盾，都在说"分数低反而好"。

### 3.1 关键推论：权重方向错配，不是权重数值不对

以**经典多因子**为例，把权重与实测 IC 并列：

| 因子 | 策略权重 | 实测 IC(T+5) | 贡献方向 |
|---|---|---|---|
| TREND_MA | **+0.20** | −0.062 | ✗ **反向** |
| MOM_20 | **+0.20** | −0.058 | ✗ **反向** |
| TREND_MACD | **+0.15** | −0.029 | ✗ **反向** |
| VOL_RATIO | **+0.12** | −0.031 | ✗ **反向** |
| VOL_PRICE | +0.08 | +0.026 | ✓ 同向 |
| VOLATILITY_20 | −0.125 | +0.008 | ✓ 同向（低波动好） |
| MAXDD_60 | −0.125 | +0.039 | ✓ 同向（低回撤好） |

**该策略 0.67 的绝对权重压在方向相反的因子上，只有 0.08 的 VOL_PRICE 是真正同向。**
风险族（合计 0.25 权重的负向）方向是对的——**问题集中在动量/趋势族**。

> 这解释了为什么"调权重"此前怎么看都像盲调：
> **不是权重该给 0.15 还是 0.25 的问题，而是有 4 个因子该给负号。**

### 3.2 一个可疑因子：LIQUIDITY_20 的 IC 与分组收益严重矛盾

- IC(T+5) = −0.045（负）
- 但 D10−D1(T+5) = **+5.763**（极高正）

两者符号相反，说明该因子与前向收益是**强烈非线性**的，
用线性加权（百分位×权重）表达它会系统性失真。**修复不应只是改符号。**

同理 VOL_PRICE 的 D10−D1 = +5.108 也异常大，需要单独看分布。

## 5. 结论：回答"是策略有问题，还是体系不可行"

**两者都有，但主因可以定位：**

1. **因子库本身有信息，但方向被设反了。**
   动量/趋势族（`TREND_MA` / `MOM_20` / `RSI_14` / `VOL_RATIO`）在 2025-10 至 2026-08
   这段区间上是**反转**而非动量：涨得多的后续跑输。
   策略把"趋势强"当成买入理由（正权重），于是**系统性买在反转前**。

2. **因此"策略打分体系不可行"这个判断下早了。**
   实测 6 个显著因子说明**横截面是可预测的**（IC 有非零真值），
   只是符号与既有约定相反。这属于**可修**，不属于"因子无信息"。

3. **但合成本身没有错。** 加权平均只是忠实汇总了符号错误的输入。
   若把 4 个反向因子的符号翻正，按当前权重，合成分数 IC 有望由 −0.068 转为正。
   **这正是阶段 2/3 要验证的**——且必须用**样本外**区间验证，不能用本区间调参后自证。

4. **基本面那条线是彻底空的。** 综合/多维有 40% 权重在基本面因子上，
   而这 5 个因子从未触发 ⟹ 那 40% 是空转，`RE_NORMALIZE_OVER_AVAILABLE`
   把它剔掉后按比例放大技术因子。**"综合/多维"与"经典/趋势"的差异，
   当前纯粹来自技术因子的重新配权，而非真的多了基本面信息。**

## 9. 更正一处此前的误判："绝对阈值因子未做截面标准化"

我在阶段0/阶段1 的早期叙述里曾说 `TREND_MACD` / `RSI_14` 这类因子
"用绝对阈值、不随截面自适应"，并把它列为一条待修缺陷。**这个判断是错的。**

读 `CrossSectionNormalizer` 后确认，横截面管道是三步：

```java
CrossSectionNeutralizer.Result neu = CrossSectionNeutralizer.neutralize(compact, ...);
List<Double> z   = CrossSectionFactorMath.robustZScoresOnResiduals(neu.residuals());
List<Double> pct = percentileRanking(z);        // ← 最终落到百分位排名
```

即 **去极值 → 稳健Z(残差) → 百分位排名**。最终参与加权的是**百分位(0~100)**，
不是原始值，也不是绝对阈值。**绝对阈值在统一层已经被消掉了。**

实测印证（2026-07-01，综合策略，5163 只）：

| 因子 | min | p10 | p50 | p90 | max | 近似唯一值占比 |
|---|---|---|---|---|---|---|
| RSI_14 | 0.00 | 9.65 | 49.82 | 90.37 | 99.99 | 1.000 |
| TREND_MACD | 0.57 | 10.04 | 51.78 | 90.49 | 99.50 | 0.978 |
| KDJ_J | 0.00 | 10.03 | 51.37 | 90.43 | 100.00 | 1.000 |
| VOL_RATIO | 0.00 | 11.75 | 51.91 | 90.50 | 98.58 | 0.970 |

全部铺满 0~100、中位数≈50、p10/p90≈10/90 ⟹ **确为横截面均匀排名**。

⟹ 目标 (3) 里"修正绝对阈值因子为截面标准化"这一项，**在统一层已是既成事实**，
不需要再做。此前把它当缺陷是我的误判，在此更正。

### 9.1 但由此发现一个新的真实缺陷：`VOL_TURNOVER` 有 85% 并列值

同一张表里 `VOL_TURNOVER` 的**近似唯一值占比只有 0.153** ——
5166 只股票里只有约 15% 的取值互不相同，即约 **85% 是重复值**。
其余因子都在 0.92~1.00。

含义：该因子在横截面上被压成少数几档，百分位排名大量并列，
**它携带的截面分辨信息远低于其他因子**。这与阶段1 测出的
`VOL_TURNOVER` IC(T+5) = −0.005（t = −0.17，近似为 0）一致 ——
一个近乎常数化的因子当然测不出 IC。

**这是"因子构造层面"的缺陷，不是权重能修的**，列入阶段3 待查：
需确认 `VOL_TURNOVER` 的原始定义是否用了粗离散化（分档/取整）导致并列。

### 9.2 `VOL_TURNOVER` 并列的根因已定位：**上游精度只有两位小数**

追到源头：`FactorCalculator:240` 直接取信号 bar 的
`market_data.turnover_rate`，不做任何变换。查原始列：

| 日期 | 行数 | NULL | 不同取值 | 唯一值占比 |
|---|---|---|---|---|
| 2026-07-01 | 5,456 | 0 | **1,233** | 0.226 |
| 2025-11-21 | 3,624 | 0 | **942** | 0.260 |

原始取值就是**两位小数**（最高频：1.31 出现 26 只、1.88 出现 22 只 …）。
5,456 只股票只有 1,233 个不同取值 ⟹ 平均每个取值压 **4.4 只**，
排名后并列进一步放大到 85%。

**结论：不是代码 bug，是数据精度上限。**
该因子在横截面上最多只有约 1,200 个可分辨档位。
影响评估：并列组平均只有 4~5 只，**仍保留大部分截面信息**，
不构成"因子失效"；但这解释了为什么它的 IC 天然偏低（大量并列会衰减 Spearman）。
若要提升，只能换更高精度源或改用"成交额/流通市值"自算，属数据层改动，**本轮不做**。
