# 多维度打分口径说明（系统实现版）

本文档冻结与《打分系统说明》一致的计算口径；与示例演算冲突时以**正文规则**为准。

## 1. 净利润增速得分（冻结）

- 采用正文分段：**净利润同比增速 &lt; 0% → 0 分**。
- 示例中「负增长给 3 分」视为演示笔误，系统不采用。

## 2. 各维度与综合分

- **技术面得分**：  
  `MACD得分×0.4 + RSI得分×0.3 + KDJ得分×0.2 + 成交量得分×0.1`  
  子项得分区间按原说明（MACD、RSI、KDJ、成交量规则）。

- **基本面得分**（0～10）：  
  五项分段各 0～10 分后加权：  
  `营收×0.25 + 净利×0.25 + ROE×0.2 + 负债率×0.15 + PE相对行业×0.15`。

- **政策面得分**：人工/NLP 定性区间映射为约 **-10～+10**；本系统为**行业级**新闻关键词与标题匹配近似（见 `DomesticPolicyIngestService`）。

- **市场轮动得分**：资金流向 + 板块热度 + 融资融券变动 **相加**（与原说明一致）。

- **行业对比得分**：营收增速、ROE、PE 三项相对行业均值，每项优于 **+2**、劣于 **-2**，合计 **-6～+6**。

- **综合得分**：  
  `技术面×0.3 + 基本面×0.3 + 政策×0.15 + 轮动×0.15 + 行业对比×0.1`

## 3. 操作建议阈值（冻结）

- **买入**：综合得分 ≥ 8，且技术面 &gt; 5，且基本面 &gt; 6。  
- **持有**：5 ≤ 综合得分 &lt; 8。  
- **卖出**：综合得分 &lt; 5，或技术面 &lt; 3，或基本面 &lt; 4。  
- **风控**：技术面 &lt; -5 → 强制卖出；技术面 &gt; 12 且基本面 &gt; 8 → 部分止盈。

说明：技术面子项按说明可产生负向 MACD/KDJ 等，故「技术面总分」允许为负；阈值与原文一致。

## 4. 数据缺失降级

- 无财报：基本面分项按中性 **5 分** 参与加权（或仅 PE 可用时部分使用行业 PE）。  
- 无资金流/融资融券：轮动对应子项 **0 分**。  
- 无政策匹配：政策面 **0 分**。  
- 行业样本过少：行业对比 **0 分**。

## 5. 因子版本

- `trend_signal_v1`：原趋势模型（趋势+乖离+量能+支撑+MACD+RSI），与本文多维度独立。  
- `multi_dim_compute_v1`（当前默认）：**第一版纯可计算**多维度，落库 `stock_multi_dim_score`。不调用政策抓取、资金流、融资、财报等外部接口；仅用库内 K 线、`market_data` 当日 PE、`stock_info` 行业/板块标签。

### 5.1 `multi_dim_compute_v1` 权重与含义

各子维度先归一化到约 **0～10**，再加权求综合分（便于与操作建议阈值对齐）：

| 维度 | 数据来源 | 说明 |
|------|----------|------|
| 技术面 | K 线计算 | 与全文「MACD/RSI/KDJ/成交量」加权一致，再线性映射到 0～10 |
| 估值（原基本面退化） | 当日 PE + 行业 PE 均值 | 仅 **PE 相对行业** 一项 0～10 分 |
| 板块轮动 | 全市场 K 线聚合 | **板块**内个股 5 日收益均值，板块间排名 → 原「板块热度」±6/−3 规则，再映射到 0～10 |
| 行业相对 | K 线 + PE | **PE 相对行业**与 **5 日涨幅相对行业均值** 各 ±2 分，合计 −4～+4，再映射到 0～10 |

综合分公式：

`综合 = 0.38×技术面_norm + 0.27×PE估值 + 0.20×板块_norm + 0.15×行业相对_norm`

政策面、主力净流入、融资余额等本版**不参与**；后续接入 API 后可再扩展因子版本。
