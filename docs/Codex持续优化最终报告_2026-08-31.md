## 四、需用户决策项（本期未擅自接入付费/外部源）

以下为**披露/正确性兜底**已落地，但**根因需官方数据源或经营决策**，归「需要用户决策」：

1. **真实估值因子数据源**：`market_data.pe_ratio/pb_ratio` 仍无 Java 写入方且可能全 NULL。消费方现有兜底（缺失用行业真实中位数，非 0；缺失不入中位数）已防止污染排序/稳定列，但真正估值因子仍依赖接入官方 PE/PB 数据。**建议**：接入权威数据源（需凭据/费用）后，由 DataController 增量回填。
2. **真实市值可靠性**：`totalMarketValue` 现标 `UNKNOWN_LEGACY` → 截面中性化把 size 暴露排除。已显式披露（R6），但根治需可信官方市值源。
3. **官方上市/退市日期**：PIT 股票池以 `security_master_history` 为准，无历史时回退当前截面并标 `PIT_LIMITED`（R2/R12 强化了不变量测试与披露）。若要彻底消除历史偏倚，需接入官方长期上市/退市历史。
4. **模拟/实盘边界**：本批仅做金融正确性、披露与测试加固，未启用真实交易、未发版、未建 PR。

## 六、残余风险（诚实记录）

1. **估值因子仍依赖外部数据**（见第四节第 1 条）：即使兜底正确，缺数据时估值类因子信息量有限。
2. **size 中性化被排除**：市值不可靠时截面中性化少了 size 维度，相关选股信号不完全。
3. **PIT 历史池回退路径**：无 `security_master_history` 时回退当前截面并标 `PIT_LIMITED`，历史回测在「未初始化主数据历史」环境下仍可能不完全是历史口径（已强披露）。
4. **P3 属于低风险打磨**：排序/筛选、类型化、文档同步等改动不改变打分数值，风险低；但 UI 行为（sortable/过滤）未做浏览器端自动验证，仅 vue-tsc + build 通过。
