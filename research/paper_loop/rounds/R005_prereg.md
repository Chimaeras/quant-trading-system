## 2. 假设

**H1（本轮要杀死的对象）**

> 项目在「**信号/打分产出入库**（`selector_result` / `selector_result_item`）→
> **标签生成**（`LabelFactoryService`）→ **回测取数与评估**（`ScoringBacktestService`）」
> 三段链路上，**在 `t` 时刻用于生成信号或用于评估的信息，均可在 `t` 时刻（或更早）合法获得**；
> 且**每条被持久化的记录都能复现它自身声称的口径**。

**默认立场（协议原文）**：假设 H1 是**错的**，本轮的任务是**杀死它**，不是证明它对。
连续多轮证伪是可接受的正常结果。

### 2.1 为什么 H1 是**可证伪**的（与 R004 同等强度要求）

H1 有两个可分离的子命题，各自有可执行的反证来源：

| 子命题 | 反证来源（可执行） |
|---|---|
| **H1a 时点合法性**：持久化特征可由 **≤ `trade_date`** 的数据重算 | 用 `market_data` **重算**存储特征；若只有**后用未来数据**的约定能对上，则 H1a 被杀 |
| **H1b 口径自洽**：记录能复现它**自己声明的**约束 | 把「声明字段」与「持久化值」做交叉断言（如 `avg_amount20` vs `min_avg_amount`）；若存在**不可能同时为真**的组合，则 H1b 被杀 |

### 2.2 本轮的判定强度**上限**（预先自我降级，防止事后夸大）

本轮判定的是「**声明与实现/工件是否自洽**」，
**不是**「策略收益是否被前视污染」。本地缺少回答后者所需的数据（见 §5）。
⟹ 报告中**禁止**把「契约违规」表述为「策略被高估」，也**禁止**给出任何收益修正量。

## 4. 八轴判据（**逐条给出可触发性**，沿用 R001/R003/R004 教训）

### 轴清单与判定词汇

判定词汇（**四值，互斥**）：

| 值 | 含义 |
|---|---|
| `VIOLATED` | 有**可执行证据**表明该轴的要求在本项目**不成立** |
| `NOT_VIOLATED` | 有可执行证据表明该轴的要求在本项目**成立** |
| `N/A` | 该轴要求的对象在本项目**不存在**（须给出理由） |
| `UNDETERMINABLE` | 本地代码/数据**不足以**判定（须给出缺什么） |

### 前置闸（不过则 `INVALID`，**不得产出任何轴结论**）

**G1 阳性对照**：canary 必须对 3 处**故意注入**的违规全部报警（`flag=3/3`）。
**G2 阴性对照**：对**未注入**的合规样本必须**零误报**（`fp=0`）。
**G3 连接性**：canary 的每个注入必须接到**同一份**用于真实数据的检测函数上——
与检测真实数据的调用是**同一函数、同一参数**（R003 教训：金丝雀第一次因"信号没接上"返回主策略自己的 IC）。
三项任一不过 ⟹ `INVALID`。

### A1 — L1.1「无测试集 / 训练测试在所有步骤上分离」（**结构性**）

- **判据**：IS/OOS 是否存在，且**按时间**分离（`max(IS) < min(OOS)`）。
- **触发 `VIOLATED`**：存在任何一处切分使 IS 与 OOS 的数据日期区间**交叠**，或消费方拿到切分信息后仍用全样本。
- **`N/A` 条件**：无。

### A2 — L1.2「预处理阶段隔离」（**结构性**）

- **判据**：打分链路中是否存在**用全样本（含 OOS）估计**的归一化/标准化/截面分位，再回填到 IS。
- **触发 `VIOLATED`**：存在这样的路径，且有代码证据表明其参数由含 OOS 的样本估计。
- **注意**：截面内当日横截面归一化**不算**违规（它只用当日信息）。判定必须区分「**跨时间**全样本估计」与「**当日截面**估计」。

### A3 — L1.3「特征选择阶段隔离」（**结构性**）

- **预判**：`UNDETERMINABLE`。理由：`factor_version` 的权重来源无记录。
- **触发 `VIOLATED` 的条件**：若扫描发现**权重/OOS 区间**被写进同一工件（即证据存在），则改判。

### A4 — L1.4「重复与重复的处置」（**数值**）

三项检查，任一触发即 `VIOLATED`：

| 检查 | 触发阈值（冻结） |
|---|---|
| A4a `(result_id, stock_code)` 重复 | 重复对数 **> 0** |
| A4b `(trade_date, factor_version, topn)` 产生 >1 个 `result_id` | 组数 **> 0** |
| A4c 同一股票在**重叠持有窗口**内被同一 `factor_version` 重复选中 | 重叠样本占比 **> 50%** |

- A4c 是**登记项**（重叠在日频选股里是常态，不等于泄漏）；它触发时**不单独**判 `VIOLATED`，
  必须与 A7 联合，且报告中说明「重叠是设计使然，非证据」。⟹ **A4c 只登记，不判**。

### A5 — L2「特征的合法性（逐特征论证）」（**结构性**）

- **判据**：对 `selector_result_item` 的每个持久化特征列，回答「在 `trade_date` 当天是否可得」。
- **触发 `VIOLATED`**：存在某个**字段级**证据表明该字段的取值时点**严格晚于** `trade_date`
  （例如字段名/注释/关联查询表明它用了 `trade_date` 之后的窗口）。
- **注意**：**字段语义不清**（不知道它到底是什么窗口）⟹ 判 `UNDETERMINABLE`，**不判** `VIOLATED`。

### A6 — L3.1「时间泄漏」（**数值，核心**）

三项检查，**A6a 与 A6b 分别判**：

**A6a 溯源滞后（登记 + 弱判定）**

- 计算 `DATEDIFF(created_at, trade_date)` 的分布。
- **触发 `VIOLATED`**：`lag ≥ 2` 的运行占比 **> 50%**。（冻结值：实测 9/67 ≈ 13.4% ⟹ **不会**触发）
- 无论是否触发，分布**必须**完整登记。

**A6b 特征可重算性（核心判据）**

- 对象：`unified_classic_v1`（特征已填充的 2834 行）。
- 方法：对每个 `(stock_code, trade_date)` 用 `market_data` **重算**特征，在 **4 种约定**下比较：

| 约定 | 定义 | 性质 |
|---|---|---|
| `PIT_INC` | 窗口含 `trade_date`（`[D−n+1, D]`） | PIT |
| `PIT_EXC` | 窗口不含 `trade_date`（`[D−n, D−1]`） | PIT |
| `LA_1` | 窗口含 `D+1`（`[D−n+2, D+1]`） | **前视（注入）** |
| `LA_5` | 窗口含 `D+5` | **前视（注入）** |

- 比较对象：`ret20`（n=20）、`ret60`（n=60）、`avg_amount20`（n=20 的成交额均值）。
- **匹配容忍度**（冻结）：相对偏差 `≤ 1e-3`；覆盖度要求 **≥ 200 个可用行**，否则 `UNDETERMINABLE`。
- **分类规则（冻结）**：
  - `PIT_MATCH`：最优 PIT 约定的匹配率 ≥ **0.90** 且 ≥ 最优 LA 约定；
  - `LOOKAHEAD_MATCH`：最优 LA 约定的匹配率 ≥ **0.90** 且 > 最优 PIT 约定 **+0.05**；
  - `NEITHER`：其余 ⟹ `UNDETERMINABLE`（**不得**判 `VIOLATED`）。
- **触发 `VIOLATED`**：至少一个被检特征的分类为 `LOOKAHEAD_MATCH`。
- **必须同时报告**：每个特征 × 每个约定的**匹配率矩阵**（不能只报结论）。
- **预判**：`NEITHER` ⟹ `UNDETERMINABLE`（P-1）。

### A7 — L3.2「训练/测试依赖的处置」（**数值，部分**）

- **判据**：同日截面样本是否被当作独立；持有窗口是否重叠。
- **检查**：
  - A7a 各 `trade_date` 的样本量分布（是否被当作独立观测）；
  - A7b 同一 `(stock_code)` 在 `factor_version` 内的持有窗口重叠率。
- **触发 `VIOLATED`**：重叠率 **> 50%** 且**无任何处置痕迹**（无去重键、无窗口标记）。
- **否则**：登记为 `NOT_VIOLATED` 或 `UNDETERMINABLE`。

### A8 — L3.3「测试分布匹配论断分布」（**结构性，只登记**）

- 事实：PIT 股票池缺失 = `B-R001-02`；板块断层 = `B-R001-04`。
- **本轮处置：只登记，不判 `VIOLATED`**。理由：该缺陷已由既有队列项承担，
  本轮重复定罪不产生新信息，且会让"轴被触发"的数量虚高。

### A9 — **非泄漏轴**：工件能否复现其**自身声明的准入约束**（**数值**）

> 判据出处 = KN2022 §2.5 的可复现性扩展定义（「**bug 也算不可复现**」）。
> **明确声明：本轴不在论文的 8 类泄漏分类法内**，由我自行提出并冻结，防止事后被误认为论文轴。

- **判据**：对每一行 `selector_result_item`，其**持久化特征**必须与其**父运行的声明约束**相容。
- **触发 `VIOLATED`**（三条全部成立才算）：

| # | 条件（冻结） |
|---|---|
| A9a | 存在行满足 `avg_amount20 = 0` **且** 父运行 `min_avg_amount > 0` |
| A9b | `avg_amount20` 的 **NULL 计数 = 0**（⟹ 占位值与真实 0 **不可区分**） |
| A9c | 上述行数占该运行返回行数的比例 **> 0** 个（即非空集） |

- **同时必须登记**：零值率**按 `factor_version` 分组**（不能只报全局 42.7%）。
- **本轴的影响范围声明**：`VIOLATED` 只意味着「**工件无法复现自身准入声明**」，
  **不意味着**选股结果错误、也不意味着收益被高估。

### RX2 — **非泄漏轴**：同一逻辑阈值在不同版本间的**量纲不一致**（**数值，登记为主**）

> 同样**不在**论文分类法内。

- **判据**：`selector_result.min_avg_amount` 的取值集合。
- **触发 `VIOLATED`**：存在两档取值，其比值 ∈ **[100, 10000]** 的整数幂，
  且被**不同 `factor_version`** 使用 ⟹ 判定为**量纲不一致**。
- **预判已观测**：`30000000.0`（`v1` / `geopolicy_news_v1` / `codex_short_cycle_v2_neutral`）
  与 `30000.0`（`trend_signal_v2` / `multi_dim_v2_normalized` / `comprehensive_v2_fundamentals`）共存，比值 **1000×** ⟹ **会触发**。
- **影响范围声明**：与既有 `D-R001-01`（`amount` 单位错配）**同源**；本轮**不合并**判决，
  只把它作为 `D-R001-01` 的**新增独立证据**登记。

**该决定的代价必须写明**：若 A6b 在某段时间上恰好对上、另一段对不上，本方案**不会**发现。
⟹ 报告中必须报告 A6b 匹配率矩阵的**逐行明细**，而不是只报一个总匹配率。
