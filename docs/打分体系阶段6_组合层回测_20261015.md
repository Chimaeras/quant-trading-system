> 生成日期：2026-10-15
> 脚本：`.tmp_quant_watch/portfolio_backtest.py`（报告：`bt_portfolio_report.txt`）
> 策略：`MULTI_DIM`（多维）　TopN=20　单边成本 15bp（往返 30bp）

## 0. 本文首先更正原始报告的一处标注错误（必读）

`bt_portfolio_report.txt` 的**两个方案标签写反了**，导致它的判读结论方向相反。必须在此更正，否则会得出「符号修正改善了组合业绩」的错误结论。

证据（脚本 `portfolio_backtest.py:219-220, 264-265`）：

```python
base_w  = fetch_weights().get(S) or {}                                  # 引擎当前权重 = 原始正号
flipped = {f: (-w if f in STABLE_NEG else w) for f, w in base_w.items()} # 翻符号版本

for tag, w, dts in (("现状人工权重", base_w,  base_days),      # ← 实际是【原始权重】
                    ("符号修正后",   flipped, flipped_days)):  # ← 实际是【翻符号】
```

引擎当前服务的权重已核验为**原始正号**（`MULTI_DIM`: `TREND_MA +0.14 / RSI_14 +0.09 / QUAL_LEV −0.04 …`，其中 `QUAL_LEV` 本来就是负号）。因此：

| 报告里的标签 | 实际含义 | 报告给的累计收益 |
|---|---|---|
| 「现状人工权重」 | **翻符号版本（已被我撤回）** | −66.93% |
| 「符号修正后」 | **原始权重（当前生效）** | −9.99% |

⟹ 报告结尾「⟹ 符号修正在组合层同样改善」**是错的**；正确读法是**原始权重在组合层明显更好**。本文下面用更正后的标签重述全部数字。

---

## 1. 方法与口径

| 项 | 设定 |
|---|---|
| 信号时点 | T 日收盘后得到分数 |
| 调仓时点 | **T+1 开盘**（A 股 T+1，不能在 T 日成交） |
| 持仓 | Top20 等权 |
| 换手 | **仅在成分变化时交易**（不做每日再平衡，否则会虚增换手） |
| 成本 | 按**成交额**单边 15bp 扣（往返 30bp） |
| 停牌 | 无次日开盘价则跳过该笔卖出；估值回退到上一有效价 |
| 估值 | 收盘价市值 |

**成本分离**：同一选股路径跑两遍，一遍扣费、一遍 `one_way_bp=0`，从而把「选股能力」与「成本拖累」分开。

---

## 2. 结果（标签已更正）

### 2.1 两个方案

| 指标 | 原始权重（当前生效） | 翻符号版本（已撤回） |
|---|---|---|
| 累计净值 | 0.9001 | 0.3307 |
| **累计收益** | **−9.99%** | **−66.93%** |
| 年化收益 | −18.71% | −88.66% |
| 年化波动 | 28.42% | 75.06% |
| Sharpe | −0.59 | −2.43 |
| 最大回撤 | −23.41% | −66.93% |
| 日均换手 | 0.990 | 1.041 |
| **不计成本累计收益** | **+8.23%** | −59.87% |
| 累计成本（占初始净值） | 17.90% | 14.39% |

**读法**：
1. 原始权重在组合层全面优于翻符号版本（累计收益差 +56.9pp、Sharpe 差 +1.84、回撤浅 43.5pp）。这与撤回说明中的结论一致，**再次否证**「翻符号更好」。
2. **不计成本时原始权重是正的（+8.23%）**，扣 30bp 往返成本后变成 **−9.99%**。
   ⟹ **成本吃掉了约 18.2pp**，策略的毛收益扛不住这个换手率。这是比「符号」更关键的问题：日均换手 0.99 意味着**大约每天换掉整个组合**（Top20 逐日重合度实测均值 9.3/20）。
3. 翻符号版本毛收益就是 −59.87%，**并非被成本拖累，而是选股方向本身错**，两者性质不同。

### 2.2 对照基准（关键）

| 基准 | 累计净值 | 累计收益 | 年化 | 波动 | Sharpe | 最大回撤 |
|---|---|---|---|---|---|---|
| ① 等权持有全截面（不换手、不扣成本） | 0.9933 | −0.68% | −0.77% | 20.62% | 0.07 | −24.61% |
| ② 等权持有**合格池**（策略的选股范围，不扣成本） | 0.9656 | **−3.44%** | −3.97% | 20.50% | −0.09 | −24.42% |

**基准 ② 才是真正的控制组**：策略只从「通过闸门（min_avg_amount / min_bars）的合格池」里选股，而合格池本身是一个**有偏子集**（天然排除大量小盘股）。拿策略去比全市场等权，会把「合格池 vs 全市场」的差异错记到策略头上。

- 策略（原始权重，未扣成本 +8.23%）**优于**合格池（−3.44%）；
- 但策略（扣成本 −9.99%）**劣于**合格池（−3.44%），落后约 6.6pp。

⟹ 结论：**在覆盖成本之前，这套打分相对合格池有正的选股价值；覆盖 30bp 往返成本之后，价值被抹掉并转负。** 问题从「方向对不对」变成了「换手太高 / 单次预测幅度太小，撑不起交易成本」。

## 3. 与阶段1/3/5 的关系

| 阶段 | 口径 | 看到的现象 |
|---|---|---|
| 阶段1 | 逐因子 Rank IC | 多数因子 \|IC\| 很小，不稳定 |
| 阶段3 | 按 IC 调权重/符号 | 结论随口径翻转（已撤回） |
| 阶段5 | 概率校准 | 区分度仅 ~3.9pp，isotonic 反而变差（Brier 0.25396 > 常数基准 0.25022） |
| **阶段6** | **组合层净值** | **原始权重毛收益为正、净收益为负；十分位 D10−D1 ≈ −0.32bp** |

四个口径互相印证同一件事：**分数在「极端端」（Top20/十分位两端）几乎没有可靠的收益排序能力**。组合层的毛收益 +8.23% 主要来自「合格池里选 20 只等权」这一动作本身，而不是来自「选出更好的 20 只」。

---

## 4. 口径限制（必须与结论同读）

1. 成本按**成交额**单边 15bp 扣，**未计冲击成本与滑点**；真实成本大概率更高。
2. **忽略涨跌停无法成交**、停牌处理简化、最小 100 股整手约束。
3. 基准**未扣成本**，与组合的扣费口径不完全可比（但基准不换手，成本≈0，所以影响很小）。
4. 本次跑数时**已落库截面仍在用统一口径重算中**，存在混合口径偏差；重算完成后需复跑。
5. 单年样本（2025-10 ~ 2026-08），**不构成对未来的保证**。
6. `VAL_EP` / `VAL_BP` 在权重表中仍占较大比重，但 `market_data.pe_ratio` / `pb_ratio` **100% 为 NULL**，这两个因子实际不可用 —— 组合回测因此高估了「多维」策略的真实信息量。

---

## 5. 本阶段可独立验证的结论

1. **原始权重（当前生效）在组合层优于翻符号版本**：累计 −9.99% vs −66.93%。翻符号方案已被否证。
2. **成本是主要杀手**：毛 +8.23% → 净 −9.99%，30bp 往返成本消耗约 18.2pp。
3. **扣成本后跑不赢合格池基准**（−9.99% vs −3.44%），即当前打分**没有可靠的超额收益**。
4. **换手率过高**：日均 0.99，Top20 逐日重合仅 9.3/20（中位 10，最小 0）。
5. 因此优化方向**不是再调权重**，而是**降低换手 / 增加因子信息量 / 提高单次预测幅度**。
