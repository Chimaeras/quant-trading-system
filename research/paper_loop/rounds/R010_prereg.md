## 3. 冻结的算术（**先于**任何代码；所有值由 `decimal.Decimal` 以 `prec = 60` 精确计算）

### 3.1 冻结算式（逐字）

```
doc  口径（项目声明）：  (1+r_doc)  = E·(1 − t − s) / [ P·(1 + c + s) ]
impl 口径（项目实现）：  (1+r_impl) = E·(1 − s)·(1 − c − t) / [ P·(1 + s)·(1 + c) ]
```

其中 `P` = 入场日 **raw 开盘价**，`E` = 退出日 **raw 收盘价**，
`c = DEFAULT_COMMISSION_RATE`、`t = DEFAULT_SELL_TAX_RATE`、`s = DEFAULT_SLIPPAGE_RATE`。

### 3.1b 冻结容差与阈值（**全部 P 档，项目自建**）

| 符号 | 值 | 用途 |
|---|---|---|
| `TOL` | `1e-15` | 净收益 / 因子 / 价格**绝对**残差上限（用于 V01/V02/V10 的「逐位一致」判定；`double` 往返在 1e-16 量级，1e-15 留一个数量级余量） |
| `TOL_INT` | `0` | 整数索引比较（V10）必须**精确**相等，**不设**容差 |
| `TOL_BP` | `1e-12` | bp 量级比较的绝对容差（仅用于 V05/V17 的打印校验，**不**用于放宽 `TH_BP`） |
| **`TH_BP`** | **`1.0`** | V05 的错标阈值（**自设量级线**；`R007` 教训 44：必须写成「在自设量级线下实测为 X」） |

### 3.2b 差额的**两条因子分解恒等式**（A 档，冻结）

```
f_impl − f_doc = −c + s·(c + t)          ← 主项 −c 就是「声明侧遗漏的卖出侧佣金」
g_impl − g_doc = +s·c                    ← 纯交叉项，正号
```
代入冻结费率：`f_impl − f_doc = −0.0003 + 0.0002×0.0008 = −0.00029984` ✅
　　　　　　　`g_impl − g_doc = 0.0002 × 0.0003 = +0.00000006` ✅

### 3.3 差额的**符号**（A 档推导，**不是**实测结论；实测只作校验）

```
Δnet < 0  ⟺  (1−s)U < (1+s)V
其中  U = 1 + s − c² − cs − t − ct − st ,  V = 1 + c − t − ct − s − cs
     ⟺  st·(1 + 2c + 2s) < c·(1 + c − s − cs)          ← 冻结的**等价变形**（展开后同号）
```

冻结费率下的取值（`prec=60`）：

| 量 | 值 |
|---|---|
| `lhs` = `s·t·(1+2c+2s)` | `0.00000010010000000000000000000000000000000000000000` |
| `rhs` = `c·(1+c−s−cs)` | `0.00030002998200000000000000000000000000000000000000` |
| `rhs − lhs` | `0.00029992988200000000000000000000000000000000000000` |
| `rhs / lhs`（余量倍数） | **`2997.30251748251748251748`** |

> **冻结措辞（报告必须照用）**：符号为负的**充分条件**在冻结费率下以 **≈ 2997×** 的余量成立。
> **不得**声称「对任意 `c,t,s` 恒为负」——反例存在（`s`、`t` 足够大而 `c` 足够小时 `lhs > rhs`）。
> 本轮**只**断言：**在冻结费率与 §3.4 的 9 格网格上**，`st(1+2c+2s) < c(1+c−s−cs)` **恒成立**。

**规则（冻结）**：

本轮 **19 条断言无一条**是覆盖率/命中率/频率型断言，故 **Clopper–Pearson 区间下界不适用**。逐条理由：
