# Codex 论文驱动量化改进执行协议

> 定位：`docs/Codex量化系统持续优化执行协议.md` 的**研究扩展**，不替代它。
> 主协议解决「发现问题并修复」；本协议解决「从外部研究引入新方法并证伪它」。
> 仓库范围、金融口径、安全红线沿用主协议与 `docs/研究口径规范.md`。
>
> **提交策略与轮次上限例外**：本循环每轮通过验证即 commit + push；不设固定轮次上限。
>
> 循环状态真相源：`research/paper_loop/`（见该目录 `README.md`）。

---

## 0. 为什么需要这份协议

从「读论文」直接跳到「改代码」是本领域最危险的捷径：

1. **绝大多数论文结论不可复现**，未审稿工作论文尤甚；已发表论文在样本外衰减也是常态。
2. **论文的实证环境与 A 股散户环境差异极大**：美股/加密、可做空、日内、做市流动性、零佣金、特殊样本期。
3. **本项目数据自身有已知偏差**（`研究口径规范.md` 第 5 节）：前复权价格被除权改写、`stock_info` 非 PIT、回测依赖已保存的 `selector_result` → **存在幸存者偏差与前视风险**。
4. **LLM 存在证实偏差**：如果任务是「落地这篇论文」，它会一路为结论找理由。

因此本协议的默认立场是：**「这篇论文在 A 股无效」是默认假设，agent 的任务是尝试推翻它，而不是证明它对。**

---

## 1. 核心原则（不可违背）

| 原则 | 含义 |
|---|---|
| **默认证伪** | 立项时的任务是「能不能杀死它」，不是「怎么让它 work」 |
| **无证据不立项** | 论文主张不算证据，本项目数据上的实测才算 |
| **预注册先于代码** | `rounds/Rxxx_prereg.md` 未落盘前不得写任何实验或生产代码 |
| **杀死条件不可放宽** | 一经写下，事后放宽即视为本轮结论无效 |
| **样本外隔离** | 选参数与验证用不同数据；参数定死后锁定 |
| **成本内建** | 按 `研究口径规范.md` 扣费，并处理涨停买不进/跌停卖不掉 |
| **影子优先** | 新因子先并行计算+记录，**零权重**，观察足够交易日才可提升（需用户确认） |
| **负知识同样入库** | 「某类方法在 A 股无效」比「找到一个有效因子」更值钱 |
| **宁可无产出** | 连续多轮全部证伪是**正常且可接受**的结果 |
| **非阻塞** | 单一分支阻塞 → 记录 → 切换任务，**不停止整个循环** |

## 2. 论文来源分级与初筛门槛

### 2.1 来源分级

| 级别 | 来源 | 处理 |
|---|---|---|
| A | 同行评审顶刊（JF / JFE / RFS / 金融研究 / 管理世界 等） | 可立项 |
| B | 工作论文（SSRN / NBER） | 可立项，门槛提高（须报告样本外衰减） |
| C | arXiv q-fin（PM/ST/TR） | 仅当无 A/B 替代时可立项 |
| C- | 券商金工研报 | 可参考思路，**不得单独作为立项依据** |
| X | 博客、论坛、公众号、视频 | **不得作为任何改动依据**，只能当线索去反查原始论文 |

### 2.2 初筛门槛（不满足则直接归档，不进入精读）

- 有明确的**可交易信号**定义（不是「提高预测精度」这类中间指标）；
- 报告了**交易成本**或给出换手率，能折算成本；
- 样本期不短于 5 年，且**不完全落在单一特殊市场环境**；
- 结论有**样本外或滚动窗口**验证，不是全样本 in-sample 最优；
- 年化换手率在策略容量下有意义（超过 20 倍/年的，A 股基本被成本吃掉，除非有明确低成本实现路径）。

## 3. 适配性七问（任一为「是」则归档，不实现）

1. 是否**依赖做空**或对冲工具？
2. 是否依赖**日内/高频**或 T+0？（本项目为 T+1）
3. 是否依赖**做市/流动性假设**，或在小票上假设低滑点？（本项目默认单边滑点万二）
4. 是否使用本项目**不具备的数据**（期权链、逐笔委托、盘后数据、另类数据）？
5. 结论是否来自**特殊样本期**（危机期、零利率、政策窗口）？
6. 所需数据在现有数据湖中**是否存在且 PIT 可用**？（不具备 → 记为「数据阻塞项」，驱动 QP-003/004/007，**不硬实现**）
7. 换手率 × 成本后，是否仍有正期望？

> 第 6 问的良好副作用：论文驱动会**反向暴露数据基建缺口**，须汇总进 `blocked_queue.md`。

## 4. 循环模型

```text
读取状态与台账
→ 选题（主航道缺口 / 台账空白 / 数据阻塞项）
→ 检索与初筛（门槛 2.2）
→ 精读 + 双维评估（论文严谨性 + 适配性七问）
→ 立项预注册（含杀死条件）
→ 隔离实验复现（含 baseline 对照）
→ 验证（样本外 / 成本 / 成交状态 / 多重检验 / 敏感性）
→ 判定：通过 → 影子登记 ；不通过 → 负知识归档
→ 更新台账与进度 → commit + push
→ 判断终止条件 → 下一轮
```

**一轮只处理一篇论文、一个假设。**

---

## 5. 每轮执行步骤

1. **读取状态**：`research/paper_loop/progress.md`、`paper_ledger.csv`、`decision_queue.md`、`blocked_queue.md`、本协议、`研究口径规范.md`、Git 状态与 diff。
2. **选题与检索**：用具体方法/因子关键词（如 `cross-sectional momentum A-share`、`turnover factor China`），**禁止泛搜「量化交易」**；先查台账，已归档论文不得重复研究；一轮只读一篇。
3. **双维评估**：
   - 维度 A 论文严谨性（样本期/样本外/成本/换手/可复现性/是否被反驳/多重检验/统计显著性）；
   - 维度 B 适配性七问（第 3 节）。
   任一维度不过 → 直接归档为负知识，不进入实现。
4. **立项预注册**：复制 `preregistration_template.md` 为 `rounds/Rxxx_prereg.md` 并填满（假设 / 可证伪预测 / 数据与样本 / 扣成本后验收阈值 / 样本外方案 / 与 `rule_score` 同口径基线 / **杀死条件** / 改动范围）。
5. **隔离实验**：只在 `experiments/` 下复现，**先建立或确认 baseline**，不得先改生产默认策略。
6. **验证**：
   ```powershell
   mvn test '-Dskip.frontend.build=true'
   cd modules/web ; npm exec vue-tsc -- --noEmit ; npm run build
   python -m pytest modules/compute-python/tests
   ```
   研究专项（缺一不可）：成本内建（万三/万五/单边万二）；成交状态处理且不删样本；样本外结果与衰减幅度；本轮变体数 N；关键参数 ±20% 敏感性；口径自检（`rule_score` 不得表述为上涨概率）。
7. **判定**：通过 → `shadow_registry.md`（只做影子，零权重）；不通过 → `paper_ledger.csv` + 失败原因分类。**两种情况都必须归档，不允许挂在中间。**
8. **记录与提交**：更新 `progress.md` 与台账；`git diff --check`；密钥/大文件检查；commit + `git push origin HEAD`。

---

## 6. 失败原因分类（负知识）

`适配性` / `成本高于收益` / `样本外衰减` / `数据不具备` / `方法不可复现` / `与现有因子重复` / `证据不足（全文不可访问）`

---

## 7. 权限分级

**可自动执行**：检索、阅读、评估、归档；研究区新增脚本与测试；影子因子计算与落库；台账与进度更新；按本协议每轮 commit + push。

**只能记录到 `decision_queue.md` 并跳过该分支（不阻塞循环）**：修改打分权重、因子口径、质量闸阈值；修改交易/风控/仓位逻辑；修改 `ResearchConvention` 或任何已冻结口径；修改公开 API / 前端契约 / 数据库结构；将影子因子提升为正式因子；引入新数据源或付费数据；启用真实交易或真实凭证。

---

## 8. 硬红线

1. 不得用「论文说有效」替代本项目实测证据；
2. 不得删除、跳过、放宽既有测试或断言；不得用 Mock 掩盖错误；
3. 不得用全样本最优参数充当结论；
4. 不得为达阈值而放宽杀死条件、缩短样本外区间或忽略成本；
5. 不得把 `rule_score` 表述为上涨概率、确定收益或投资保证；
6. 不得引入做空、日内、高频等与项目阶段不符的能力；
7. 不得操作本仓库以外的仓库；不得 `git reset --hard` / `checkout --` 丢弃改动 / `push --force`；不建 PR、不发版本；
8. 不得启用真实交易、索取真实凭证、向真实账户下单；
9. 不得因「连续多轮无产出」而降低标准或编造正面结论。

---

## 9. 阻塞与终止

**阻塞（记录后继续其他任务，不停止循环）**：论文全文不可访问、数据缺口、测试暂时失败、push 失败、需要用户决策、外部服务不可用。

**终止循环**：
- 用户明确要求停止；
- 运行环境或系统资源确实无法继续；
- 没有任何可安全继续的研究、实验、测试、文档或工程任务；
- 达到长期目标定义的全部完成条件；
- 必须进行真实交易、真实凭证操作或不可逆危险操作才能继续。

**正常结束（不是失败）**：连续 5 轮论文全部被初筛或适配性七问筛掉 → 输出「当前研究方向枯竭/门槛评估」报告后停止。

## 10. 人工检查点

每 3–5 轮向用户汇报，每 5/10 轮生成阶段总结：本轮论文与判定、台账新增（含负知识）、影子因子状态与累计观察交易日、数据阻塞项变化、是否出现「为了产出而放水」的迹象、下一轮建议。

**长期自治不等于可以省略人工审计**，尤其是打分权重、风险参数与实盘接口。
