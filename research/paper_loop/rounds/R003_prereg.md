## 1. 假设与杀死条件

### H1（主假设，来源：论文第 2/3 条主张）

> **H1**：按 NMV2016 的框架，R001 反转策略属于「高换手」（实测月单边换手 **747% ≫ 50%**），
> 其净价差应被交易成本消除；即**使 D1−D10 净价差归零所需的双边成本 `r*`**，
> 落在**本项目环境下真实双边成本的可能范围内**。

**杀死条件（H1 被证伪）**：见 §4 的 D1/D4。**核心量是 `r*`**——
把 R001 的成本三参数替换成一个可变的「双边总成本 `c_rt`」，逐股重算净收益，
用二分法解出让 IS 主配置 `spread_net_d1_d10 = 0` 的 `c_rt`。

`c_rt` 的参数化（**必须**保持 R001 的买/卖不对称比例，这样 `c_rt = 12bp` 精确等于冻结口径）：

```
buy_cost  = c_rt × (0.0005 / 0.0012)      # 佣金万三 + 滑点万二
sell_cost = c_rt × (0.0007 / 0.0012)      # 印花税万五 + 滑点万二
net       = exit × (1 − sell_cost) / (entry × (1 + buy_cost)) − 1
```

自检：`c_rt = 12bp` ⟹ `buy=0.0005, sell=0.0007` ⟹ 与 `ResearchConvention` 冻结口径**逐位相同**。

### H2（次假设，来源：论文第 4 条主张「等权成本是 value-weight 的 2–3 倍」）

> **H2**：若对本地**等权**策略施加论文所称的等权惩罚（冻结成本的 2× 与 3×），
> D1 净收益将不再显著为正。

**杀死条件（H2 被证伪）**：在 `c_rt = 36bp`（3× 冻结）下，D1 净收益仍 `> 0` 且 `|t_NW| > 2`
⟹ 论文的「等权惩罚」在本项目**方向上成立但量级不足以否定策略**。
反之（`≤ 0` 或 `|t_NW| ≤ 2`）⟹ H2 成立。

**说明**：论文的 2–3 倍是相对 **value-weight** 而言；本项目冻结 12bp 是一个**口径常数**，
不是 value-weight 实测值。因此 H2 是**假设性替代**，结论必须连同该偏离一起引用（§7 披露 3）。

### 参考量（不是假设、不参与判定，仅为对照论文结构）

`paper_drag_monthly(c) = 2 × 7.47 × c`（论文第 3 条主张的多空成本拖累结构）。
`c = 12bp` ⟹ 179bp/月；`c = r*` ⟹ 恰好抵消 R001 冻结毛价差 53.79bp/期。

## 2. 成本模型（全部逐股、逐日施加；**不改任何生产文件**）

`entry` = signal_date 次交易日**开盘**（前复权）；`exit` = 入场后第 h 个交易日**收盘**（前复权）。

| 代号 | 名称 | buy_cost | sell_cost | 性质 |
|---|---|---|---|---|
| M0 | 零成本 | 0 | 0 | **工具校验**：必须精确等于毛价差 |
| M1 | 冻结口径 12bp | 0.0005 | 0.0007 | **工具校验**：必须精确复现 R001 result.json |
| M2 | 一跳下界（逐股） | 0.005/entry | 0.005/exit | **模型自由下界**：A 股最小报价单位 0.01 元，市价单跨越 ≥1 跳的价差，每边 ≥半跳 |

| M4 | 2× 冻结 = 24bp | 0.0010 | 0.0014 | H2 低端（等权惩罚 2×） |
| M5 | 3× 冻结 = 36bp | 0.0015 | 0.0021 | H2 高端（等权惩罚 3×） |
| M6 | 冻结 ±20%（9.6/14.4bp） | 0.0004/0.0006 | 0.00056/0.00084 | 敏感性（R002 教训：必须报告） |

**M2/M3 的口径说明与已知偏差**：
- 一跳 = 0.01 元人民币，A 股（沪/深/北）统一，无例外。
- 仅有 `market_price_raw` **0 行**、只有前复权价（B-R001-02）。用前复权价代理真实价格：
  前复权把最新价锚定为真实价，2024–2026 窗口内除权次数少、调整幅度小，
  但对**早期**日期，前复权价**低于**真实价 ⟹ 一跳占价格比例被**高估** ⟹ M2/M3 的
  成本被**高估** ⟹ 该偏差方向**有利于**「成本足够」（即有利于 H1），是**保守**方向，
  在报告中必须写明（§7 披露 4）。
- M2 假设「市价单、无价格改善」。A 股是无做市商的纯限价簿、无 price improvement，
  该假设成立；论文自己也承认其 Hasbrouck 估计量是下界。

## 4. 判定规则（**逐条给出可触发性**，R001 教训 #2）

### 前置闸（不过则本轮无结论）

- **K2 工具校验（与 H1 同构）**：三条同时成立，否则 `INVALID`，**不得产出任何结论**：
  1. `|M0 的 spread_net − M0 的 spread_gross| < 1e-12`（成本=0 时净必须恒等于毛）；
  2. M1 在 IS 主配置上**逐位**复现 R001 `result.json`：`ic_mean`、`ic_days`、10 个分位的
     `net_mean`/`gross_mean`、`d1_net_mean`、`d10_net_mean`、`spread_net_d1_d10`、
     `universe_net_mean`、`funnel` 各计数，相对误差 `< 1e-12`；
  3. 单调性：`c_rt ∈ {0, 6, 12, 24, 36}` 上 `d1_net_mean` **严格递减**。
  > **触发条件**：任何一条不符。**预期不触发**（M1 就是 R001 的代码路径，逐位相等是恒等式级别的检查）。
- **K3 泄漏 canary**：完全预见信号（`exit/entry − 1` 作信号）的 IC `≥ 0.99`。
  > **触发条件**：`IC < 0.99`（R001 实测 1.0000）。**预期不触发**。K3 失败 ⟹ `INVALID`。

### 主判定（D1 为主，D2/D3 为附加结论）

- **K1 适用性闸**：D1 单边月换手 `≤ 0.50` ⟹ 论文的高换手门槛**不适用** ⟹
  `NOT_APPLICABLE`（本轮终止，不进入 D1）。
  > **触发条件**：换手 ≤50%/月。**实测 747%/月（`B003`）⟹ 预期不触发**。
  > 该闸存在的意义：它**可能**触发（若未来换手口径改变或策略改写），不是白写的恒假条件。
- **D1 模型自由判定（核心）**：`r*` = 使 IS 主配置净价差归零的双边成本；
  `tick_p50` = 一跳双边成本在**全池股票价格中位数**上的取值（= 7.10bp，`B003`）。
  - **D1a** `r* ≤ tick_p50` ⟹ **成本可证足以消除价差** ⟹ `PAPER_SUPPORTED`。
    （因为真实成本 ≥ 一跳下界 ≥ `r*`，这是**模型自由**的证明）
    > **触发条件**：`r* ≤ 7.10bp`。**预期不触发**（事前估算 `r* ≈ 26.9bp = 53.79/2`）。
  - **D1b** `r* > 2 × tick_p50`（= 14.19bp）⟹ 论文成立**要求**「中位价差 > 2 跳」。
    这是一个**条件性二分**，**不是**对本论文的证伪：
    - 若真实 A 股价差 ≤2 跳 ⟹ 论文被证伪；
    - 若真实价差 >2 跳 ⟹ 论文成立。
    > **触发条件**：`r* > 14.19bp`。**预期触发**。
  - **D1c** `tick_p50 < r* ≤ 2 × tick_p50` ⟹ `INCONCLUSIVE`（模型自由区间覆盖 `r*`）。
    > **触发条件**：`r*` 落在 (7.10, 14.19] bp。
- **判定语义（与前两轮一致）**：`status` 描述的是**论文主张在本项目下的命运**：
  `PAPER_SUPPORTED`（主张成立）/ `NOT_APPLICABLE` / `INCONCLUSIVE` / `INVALID`。
  台账 `当前状态` 列映射：`PAPER_SUPPORTED → ADOPT_CANDIDATE`（**须用户确认，agent 不得自行提升**）、
  `NOT_APPLICABLE → REJECTED`、`INCONCLUSIVE → INCONCLUSIVE`、`INVALID → INCONCLUSIVE`。
- **D2 横截面可证不可行子集（可判定）**：定义 `P* = 0.01 / (r* × 0.0001)` 元
  （一跳双边成本超过 `r*` 的临界价）。统计 D1 名字中 `价格 < P*` 的**占比** `s`。
  - `s ≥ 0.20` ⟹ 追加正面结论「**策略在最便宜子集上成本可证超过 break-even，可证不可行**」，
    单独登记，**不得**扩大为全策略结论。
  - `s < 0.20` ⟹ 该子集太薄，结论记为「不成立」。
  > **触发条件**：`s ≥ 0.20`。按 `B003`（p10 价 4.34 元）**事前估算** `P* ≈ 3.72 元`，
  > 占比约 5–8% ⟹ **预期不触发**（记为不成立）。
- **D3 H2 判定（可判定）**：见 §1。**预期**：`c_rt=36bp` 下 D1 净收益
  事前估算 `≈ 77.92 − 36 = 41.9bp > 0` ⟹ **H2 预期被杀死**（等权惩罚量级不足）。
- **D4 OOS 报告（可判定，但只作报告）**：OOS 冻结净价差 = **−18.92bp < 0**
  （R001 `result.json`）。毛价差已为负 ⟹ **不存在任何 `c_rt ≥ 0` 能使 OOS 价差转正** ⟹
  成本**不可能**解释 OOS 的符号翻转。该结论必须写入报告：**OOS 的问题不是成本**。
  （R002 已把 OOS 问题定位为 2026-02 供应商补数导致的股票池断层。）

**判定优先级**：`K2/K3 失败 → INVALID` > `K1 触发 → NOT_APPLICABLE` >
`D1a → PAPER_SUPPORTED` > `D1c → INCONCLUSIVE` > `D1b 且价差假设未决 → INCONCLUSIVE`。
**注意**：D1b 本身不足以宣布任何一方的胜利，**除非**报告同时给出「需要什么数据才能决断」
（本轮答案：**逐股有效价差/逐笔成交数据**，本地 0 行 ⟹ 登记新 BLOCKED）。

## 7. 必须写入报告的披露清单

1. **股票池非 PIT**（无退市、`stock_info` 为当前快照）——沿用 R001，**所有毛/净分位收益被系统性抬高**。
2. **前复权价**：执行价非当时可成交真实价（B-R001-02，`market_price_raw` 0 行）。
3. **H2 的替代假设**：2×/3× 施加在「冻结口径常数」上，不是 value-weight 实测成本。
4. **一跳下界用前复权价代理真实价**：早期日期成本被**高估**，方向有利于 H1（保守）。
5. **价差不可估**（本轮新增）：`B003` 两条估计路线均被证否 ⟹ 无法给出真实成本的**上界** ⟹
   D1 的判定只能是「模型自由下界 vs break-even」的单边判定 + 条件性二分。
6. **样本期 1.7 年**（< 5 年门槛），IS/OOS 各跨单一市场状态。
7. **OOS 股票池断层**（2026-02 供应商补数 1,888 只，R002）——OOS 结果不可与 IS 直接比较。
8. **`r*` 是「R001 冻结毛价差」的函数**：R001 的价差本身不可采信，故 `r*` 只是
   **成本诊断量**，不是「策略盈亏平衡成本」的收益承诺。
