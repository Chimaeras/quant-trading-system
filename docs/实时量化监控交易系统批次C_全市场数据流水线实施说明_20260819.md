# 批次 C：全市场数据流水线实施说明

## 已实施范围

- Level 1 全市场分钟级批量扫描，记录批次覆盖率、缺失、跨页重复和耗时。
- Level 2 活跃池秒级轮询；持仓、活动委托、UNKNOWN/CANCEL_PENDING 订单强制进入。
- 成交额/成交量/波动粗筛 Top-N、最短驻留时间和容量 fail-closed。
- L1/L2 独立行情质量状态机，检测倒序、未来时间、成交量回退、价格突变和连续缺失。
- SQLite schema V3：行情批次、最新行情、质量状态、活跃池、证券规则和 universe 版本。
- Java `/api/market/security-rules` 规则快照，以及订单 metadata 中的规则版本审计。
- 监控 `/api/watch/{date}/market` 和页面 L1 覆盖率、L2 活跃池展示。
- 普通行情改为 `latest_quote` 覆盖写；事件流默认只在行情状态变化时写 QUOTE。

## 调度与配置

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| `PAPER_MARKET_PIPELINE_V2` | `1` | FULL 模式启用两级行情管线 |
| `PAPER_L1_SCAN_INTERVAL_SEC` | `60` | 全市场批量扫描间隔 |
| `PAPER_L2_POLL_INTERVAL_SEC` | `5` | 活跃池执行级行情轮询间隔 |
| `PAPER_MAX_L2_CODES` | `30` | L2 总容量；强制标的优先 |
| `PAPER_L2_MIN_RESIDENCE_SEC` | `300` | 非强制标的最短驻留时间 |
| `PAPER_QUOTE_MISSING_DISABLE_CYCLES` | `2` | 连续缺失阈值 |
| `PAPER_EXECUTION_QUOTE_STALE_SEC` | `10` | 执行级行情最大年龄 |
| `PAPER_EMIT_QUOTE_EVENTS` | `0` | 是否恢复每轮逐股 QUOTE 事件 |

`watch-serve` 默认读取 `<log-base>/watch/runtime.sqlite3`；自定义运行库时使用：

```bash
python -m paper.cli watch-serve --store-path <runtime.sqlite3>
```

## 安全边界

当前东方财富公开 HTTP 只定位为 L1 研究/筛选源；妙想单股查询用于 L2 和下单前执行确认。系统不会宣称公开 HTTP 具备交易所 tick/盘口 SLA。接入授权推送源时实现新的 `MarketDataProvider`，无需修改策略、风控和 OMS。

证券规则接口当前由 `stock_info + versioned_exchange_policy` 合成，可靠度为 `limited`。无法确认的新股特殊涨跌幅、动态停牌和价格笼子会标记为需要执行级行情确认；live 缺少规则快照时禁止下单。
