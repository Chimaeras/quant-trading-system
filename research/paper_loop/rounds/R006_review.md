## 2. 论文内容

### 2.1 核心主张

公式化 alpha 挖掘（genetic programming / RL / LLM 三类）已能大量生成候选因子，但**评估环节是瓶颈**：
现有评估要么是回测（慢、串行、对策略参数敏感），要么是相关性类指标（只衡量预测力，
**忽略时间稳定性、稳健性、多样性、可解释性**）。
论文提出 **AlphaEval**：一个**统一、可并行、免回测**的评估框架，沿五个维度打分，
并在 A 股与美股（Qlib 提供的数据集）上验证其与精细回测的一致性。

### 2.2 五个维度

| 维度 | 指标 | 论文给出的可执行定义 |
|---|---|---|
| Predictive Power | **PPS** = β·IC + (1−β)·RankIC（β=0.5） | 式 (5)(6)(7)(8)(9)(10) |
| Temporal Stability | **RRE** | 见式 (11) 附近（本轮未用） |
| Robustness to Perturbations | **PFS / PFSD** = `Corr(S, S')`，**Corr 指 Spearman** | 式 (13)(14) |
| Financial Logic | **Logic**（逻辑可解释性打分） | 附录 |
| Diversity | **DE** | 附录 |

### 2.3 与本轮直接相关的**逐字定义**

> **式 (1)**（标签口径）：`y^{ΔT}_{t,n} = (close_{t+ΔT,n} − close_{t,n}) / close_{t,n}`
> （`close_{t,n}` 为股票 n 在 t 的收盘价，ΔT 为预测区间）

> **信息系数 IC**（式 5–6）：*"Defined as the average **Pearson** correlation between the alpha scores
> S_{t,:} and the realized returns y_{t,:} across assets over all time steps"*
> `IC = (1/T) Σ_{t=1}^{T} IC_t`，
> `IC_t = Σ_i (S_{t,i} − S̄_{t,:})(y_{t,i} − ȳ_{t,:}) / ( sqrt(Σ_i (S_{t,i} − S̄_{t,:})²) · sqrt(Σ_i (y_{t,i} − ȳ_{t,:})²) )`

> **秩信息系数 RankIC**（式 7–9）：*"Defined as the average **Spearman rank correlation**
> between S_{t,:} and y_{t,:} across time"*
> `RankIC = (1/T) Σ_{t=1}^{T} RankIC_t`，
> `RankIC_t = 1 − 6 Σ_i d_i² / ( N (N² − 1) )`，`d_i ≡ R[S_{t,i}] − R[y_{t,i}]`

> **ICIR**（式 18）：*"Based on the definition of IC, ICIR can be defined as follows"*
> `ICIR = IC / sqrt( (1/(T−1)) Σ_{i=1}^{T} (IC_i − IC)² )`；**"RankICIR is defined similarly."**

> **AR / SR**（式 19–22）：多头空头**各选 K 只**，权重 `w = +1/K`（top-K）、`−1/K`（bottom-K）、
> 其余 0；`r_t = w_tᵀ y_t`；`AR = r̄ · D`（D = 252）；`SR = r̄/σ_r · sqrt(D)`，
> 其中 `σ_r = sqrt( (1/(T−1)) Σ (r_t − r̄)² )`，*"The risk-free rate is assumed to be zero for simplicity."*

### 2.4 论文自己把 ICIR 与 RankICIR **当作两个不同的量**（本轮最关键的一条）

论文 Table 1 逐行列出各已有方法使用的指标（**逐字**）：

| 方法 | Metrics |
|---|---|
| AlphaGen [25] | IC, RankIC, AR |
| **RiskMiner [15]** | **IC, ICIR, RankIC** |
| **FAMA [11]** | **RankIC, RankICIR** |
| AlphaAgent [19] | IC, ICIR, AR, IR, MaxDD |

⟹ 在该论文的分类法里，`ICIR`（建立在 Pearson IC 序列上）与 `RankICIR`（建立在 rank IC 序列上）
是**两个并列且不同的指标**，且**两者可以同时出现**。
这条是本轮 A1/A3 轴的判据来源：**名字里带不带 `Rank` 前缀，在该文献里是有区分意义的**。

### 2.5 论文的自我限制（必须同量级记录，否则会高估判据强度）

- **不给任何数值阈值**：论文不自称「IC > 0.05 算好」之类的门槛；
  它把五个维度标准化为 `m̃ = (m − μ_m)/σ_m` 后做凸组合，**横向比较的是因子之间的相对排序**，
  不是绝对合格线。
- **不涉及交易成本**：全文没有成本项，AR（式 21）建立在**毛收益**上。
- **不处理 A 股微观制度**：无涨跌停、无停牌、无 T+1、无 ST 处理；
  式 (1) 的标签是**信号日收盘到未来收盘**的简化口径。
- **不讨论并列值（ties）**：全文 `\bties?\b` 的词边界命中**全部是人名 "Tie-Yan Liu"**，
  **零处**讨论 rank 相关里的并列处理。
- **不做多重比较校正**、不讨论 IC 序列的序列相关（重叠持有期）。

### 5.1 判据强度的诚实标注

上表中「强」表示**该断言能在本地被可执行地判定真假**，**不**表示论文为此提供了阈值。
论文全程不给阈值（§2.5），所以本轮的判定都是**结构/算术型**（= 与 ≠、是否可见、分母是 T 还是 T−1），
**没有**任何「ICIR 是否够大」这类数值合格线判据。
⟹ 因此本轮**不可能**得出「项目 IC 太低」这类结论，也**不得**朝这个方向叙述。

### 5.2 关于「并列值」：这是**我的算术**，不是论文的主张（关键区分）

论文式 (8) 写 `1 − 6Σd²/(N(N²−1))`，**未加任何并列限定语**，全文也不讨论并列。
但该式只有在**无并列**时才严格等于 Spearman 的 ρ；有并列时必须用**平均秩**再求 Pearson。
⟹ 本轮凡涉及并列的断言，一律标注为 **「算术推导 / 本项目自建判据」**，
**不得**标注为「论文要求」。这与 R004 对 FF2015 的处理完全一致
（FF2015 全文 0 次提及 `transaction cost`，故 R004 的成本轴一律标为算术推导而非文献引用）。

### 5.3 关于式 (1)：**不得**用它覆盖项目冻结口径

式 (1) 是**信号日收盘 → 未来收盘**的简化标签。项目冻结口径是
**signal_date 下一交易日开盘入场、第 h 个持有日收盘退出**（`research_convention_v1`），
且带 T+1 与执行状态（`NOT_BUYABLE` / `SUSPENDED` / `NOT_SELLABLE` / `DELISTED` 不得删样本）。
按协议「论文中的简化假设不得直接覆盖项目已有金融研究口径」
⟹ 式 (1) **只作为差异记录（D-2）**，**不构成任何 kill 轴**。

## 8. 结论

**判据来源成立。** AlphaEval 提供了 IC / RankIC / ICIR 的**逐式定义**、
明确了 `IC ≠ RankIC`、`ICIR ≠ RankICIR`，并且**在 A 股上做过实验**——
这三点都是 R006 需要的、且 R005 的载体（KN2022）给不了的。

**但判据强度与 R005 同构地受限**：论文**不给阈值**（§2.5），
所以本轮只能做**结构/算术型**判定（§5.1），**不能**得出任何「数值够不够好」的结论。
凡涉及并列值（§5.2）与标签口径（§5.3）的断言，一律标注为**本项目自建判据**，
与文献判据严格分开。

**下一轮起应沿用的一条规则**：判据表必须**逐行标出「文献判据 / 算术推导 / 项目自建」**三档，
以免把自建的算术事实记成论文的主张。
