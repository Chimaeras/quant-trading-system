# 安装部署指南

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 通常随 Docker 安装 |
| Node.js | 18+ | 本地开发前端 |
| Python | 3.9+ | 本地开发量化引擎 |
| JDK | 17+ | 本地开发后端 |

## 二、Docker 一键部署

### 1. 克隆项目

```bash
git clone https://github.com/yourname/quant-trading-system.git
cd quant-trading-system
```

### 2. 启动所有服务

```bash
cd docker
docker compose up -d
```

或使用脚本：

```bash
chmod +x modules/database/deploy.sh
./modules/database/deploy.sh
```

### 3. 查看服务状态

```bash
docker compose ps
```

### 4. 访问地址

| 服务 | 地址 | 说明                 |
|------|------|--------------------|
| 前端界面 | http://localhost | 主界面                |
| 后端 API | http://localhost:8080/api | REST 接口            |
| MySQL | localhost:3306 | 用户/root, 密码/123456 |
| Redis | localhost:6379 | 缓存                 |
| InfluxDB | http://localhost:8086 | 时序数据               |

### 5. 默认账号

- 用户名: `admin`
- 密码: `123456`

## 三、本地开发

### 1. 启动基础设施

```bash
cd docker
docker compose up -d mysql redis influxdb
```

### 2. 初始化数据库

确保 MySQL 已启动，执行：

```bash
mysql -h 127.0.0.1 -u root -p123456 < modules/database/init_db.sql
```

或使用 Docker：

```bash
docker exec -i quant-mysql mysql -uroot -p123456 < modules/database/init_db.sql
```

### 3. 启动后端

```bash
cd modules/backend-java
mvn spring-boot:run
```

### 4. 启动量化引擎

```bash
cd modules/compute-python
pip install -r requirements.txt
python main.py
```

### 5. 启动前端

```bash
cd modules/web
npm install
npm run dev
```

前端开发地址: http://localhost:5173

## 四、常见问题

### 1. 端口冲突

若 3306、6379、8080、80 端口被占用，请修改 `docker-compose.yml` 中的端口映射。

### 2. 数据库连接失败

确保 MySQL 容器已完全启动（约 30 秒），可查看日志：

```bash
docker compose logs mysql
```

### 3. 前端无法访问后端

- 开发环境：确认 Vite 代理配置正确，请求 `/api` 会转发到 `localhost:8080`
- 生产环境：确认 nginx 配置中 `proxy_pass` 指向 backend 服务
