## 2. 假设

**H1（待证伪）**：R001 观测到的「IS 强（IC −0.0605 / t −7.29）、OOS 衰减（IC −0.0215 / t −0.70）」
主要是**本地面板的数据构造产物**，而不是反转信号本身的有效性衰减。

拆成两条**必须分别判定**的子通道：

- **H1a 构成通道**：2026-02 批量补录的 1,888 只代码（占 OOS 截面 **29.9%**、IS 截面 **0%**）
  改变了 OOS 截面构成，从而使全池口径的 OOS 结果失去与 IS 的可比性。
- **H1b 退市收益通道**：R001 把「退出价缺失」的信号**整条丢弃**，等价于对业绩型退市
  赋 0 收益；按 L&R/Shumway 约定补 −30% 后，R001 的反转收益应显著下降。

**默认立场：尝试杀死 H1。** H1 被杀死 = 「R001 的结论不能用数据构造解释」，
这是本轮**预期的**结果（见第 3 节 P1）。

### 2.1 先验方向声明（防止事后改口）

R001 的事后诊断（`experiments/R001_reversal/posthoc_board_consistency.json`）显示：
「构成一致池」的 OOS IC 为 **−0.0291 (t −1.08)**，比全池 **−0.0215 (t −0.70)** **更负**。
即剔除 batch 后衰减**更明显**。**若本轮复现该方向，则 H1a 应被证伪**，
且**不得**因为「终于有一个能解释衰减的通道」而改变判据。

## 5. 数据与样本

- **数据源**：本地 `quant_db.market_data`（前复权），只读。
- **面板**：与 R001 完全一致 —— 加载区间 2023-11-01 起，可用横截面 2024-01-02 → 2026-09-07。
- **去重**：与 R001 相同（保留 `id` 最大一行）。
- **可交易性**：与 R001 相同（上市满 60 交易日、非正价剔除、单日截面 ≥30 只）。
- **信号**：R001 的主配置 `past_ret_20`，`N=20`、`h=3`。**本轮不搜索新的 (N,h)**。
- **股票池定义（本轮新增，全部预先定义）**：

| 池 | 定义 |
|---|---|
| `U_all` | 某交易日面板内有价格的全部代码（= R001 口径） |
| `U_batch` | 首次出现日在 **2026-02** 的 1,888 只代码（探针 B002 固定名单） |
| `U_consistent` | 在 IS 段（2024-01-02–2025-12-31）**至少 `MIN_HIST_IS_DAYS=120` 个交易日**有价格的代码，且在 OOS 段至少 1 日有价格 |
| `U_placebo(k)` | 从 `U_all ∩ OOS` 中**随机剔除与 batch 同规模（1,888）** 的代码；独立重复 `N_PLACEBO=200` 次，种子 `20260914` |

- **attrited 定义**：某代码在面板内最后一次交易日 **< 2026-09-07**（探针实测 **99** 只）。
- **退市补偿 δ**：对「非机械性」的退出价缺失信号补收益 δ。**机械性**指退出索引越过面板最后一个交易日（所有名字都受影响，与退市无关），必须排除。

## 6. 成本与口径（必须内建，复用 `ResearchConvention`，不硬编码）

```
COMMISSION = 0.0003   # 买入佣金 万三
SELL_TAX   = 0.0005   # 卖出印花税 万五
SLIPPAGE   = 0.0002   # 单边滑点 万二
net = exit × (1 − SELL_TAX − SLIPPAGE) / (entry × (1 + COMMISSION + SLIPPAGE)) − 1
```

- 入场 `entry` = signal_date 次一交易日开盘；退出 `exit` = 入场后第 `h` 个交易日收盘；`h=3`。
- A 股 T+1；成交状态沿用 R001 的 `NOT_BUYABLE / SUSPENDED / NOT_SELLABLE / DELISTED` 编码，**不删样本**。
- 统计沿用 R001：日度截面 Spearman rank IC、Newey-West HAC(`lag = N+h+2 = 25`) t 值、十分位净收益。
- **退市补偿只作用于收益口径**：`exit_eff = exit × (1 + δ)`，δ 为**负值**；不改变成交状态编码。

## 7. 切分方案

- **IS**：2024-01-02 → 2025-12-31（485 交易日）；**OOS**：2026-01-01 → 2026-09-07（160 交易日）。
  **与 R001 完全一致，不得改动**（改动 OOS 区间即触发 K6）。
- 构成通道的比较**只在 OOS 段内做**（因为 batch 只影响 OOS）；IS 段作安慰剂对照（见 T2）。
- IS 内部再分 IS-A（2024）/ IS-B（2025），用于检验「IS 内部是否也存在构成变化而其 IC 未随之变化」。

## 8. 验收阈值（扣除成本后）

**H1a 成立需同时满足**：

1. **统计**：`|ΔIC_real| > p95( |ΔIC_placebo| )`，其中
   `ΔIC_real = IC_OOS(U_all) − IC_OOS(U_consistent)`；
   placebo 分布由 `U_placebo(k)` 200 次重复得到（同规模随机剔除）。
2. **经济**：`batch_explained_share = (IC_OOS(U_consistent) − IC_OOS(U_all)) / (IC_IS(U_all) − IC_OOS(U_all)) ≥ 0.50`，
   即 batch 至少要解释 IS→OOS 衰减的一半。

**H1b 成立需**：δ=−30% 时 D1 净收益的下降 ≥ 26.9bp（= R001 价差 +53.7bp 的一半）。

**最终判定**：

| 情形 | 判定 |
|---|---|
| K4/K5/K6/K7 任一触发 | **INCONCLUSIVE** |
| H1a 与 H1b **都**不成立 | **REJECTED**（数据库构造解释被证伪 = 负知识） |
| H1a、H1b 恰有一个成立 | **INCONCLUSIVE** |
| H1a 与 H1b 都成立 | ADOPT_CANDIDATE（**仍不得进入生产**；按协议只能登记影子，且提升需用户确认） |

> 注意：本轮**无论何种判定都不产生新因子**。产出是负知识或数据基建结论。

## 9. 杀死条件（**不得事后放宽**）

| ID | 条件 | 触发后果 |
|---|---|---|
| **K1** | 构成通道**统计判据**不满足：`|ΔIC_real| ≤ p95(|ΔIC_placebo|)` | **H1a 证伪** |
| **K2** | 构成通道**经济判据**不满足：`batch_explained_share < 0.50` | **H1a 证伪** |
| **K3** | 退市通道量级不足：δ=−30% 时 D1 净收益下降 < 5bp | **H1b 证伪** |
| **K4** | **阳性对照失败**（估计量无鉴别力）：`|IC(U_batch-only) − IC(U_consistent-only)| < 0.002` | **INCONCLUSIVE**（空实验，不得判 REJECTED） |
| **K5** | **管线校验失败**：完全预见金丝雀 IC < 0.99 | **INCONCLUSIVE** |
| **K6** | 成本未内建、或 IS/OOS 区间被改动、或安慰剂规模 ≠ 1,888 | **本轮无效** |
| **K7** | 变体数超过预注册上限 `MAX_VARIANTS = 12` | **本轮无效**（视为数据窥探） |
| **K8** | ±20% 敏感性下任一 δ 使 H1b 结论反转 | H1b 标记为**不稳定** → 归入 INCONCLUSIVE |

**K4 的设计说明（修正 R001 的 K7 教训）**：R001 的 K7 把「泄漏能否被检出」写成
「泄漏信号是否更强」，二者并非同构条件，导致工具校验恒触发。本轮 K4 是**同构**的：
它检验「估计量能否区分两个**构成差异最大**的池」。若连最大差异都区分不了，
则构成通道的一切结论都无鉴别力，故判 INCONCLUSIVE 而非 REJECTED。
同理，K1/K2/K3 都写成**可触发**形式：探针已确认三条通道的信号质量非零（见审查 §6）。
