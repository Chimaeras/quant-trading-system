## 0. 本文的三个结论

1. **原处置表有一个方法论缺陷**：它按「IC 为正 = 方向正确」判断，忽略了
   `VOLATILITY_20`/`MAXDD_60`/`QUAL_LEV` **本就带负权重**。正确判据是**符号校正贡献**
   `sign(w_f) × IC_f`。
2. **合格池口径下，几乎全部因子的 \|t\| < 2** —— 我此前「多数因子显著为负」的说法
   是**全截面口径**的产物。合格池下 5 套策略共 45 个(策略,因子)组合里，
   只有 4 个达到 \|t\| ≥ 2。
3. **修权重符号在样本外确实是正的，但未达统计显著**：
   现状权重测试期 IC **−0.0175**，仅调符号后 **+0.0261**（配对 t=+1.23，胜率 55.4%）。

## 3. 我自查出的两个脚本错误

### 3.1 「符号全对上限」列是无意义的

`disposition_v2.py` 里：

```python
contrib = (1 if w >= 0 else -1) * m     # 符号校正贡献
pred  += w * m                          # 原样加权
upper += abs(w) * contrib               # ← 错
```

`abs(w) * sign(w) * IC = w * IC`，与 `pred` **恒等**，所以两列差恒为 0.0000
（输出里正是如此）。该列不携带任何信息。**正确的「若符号全对」应为 `Σ|w_f|·|IC_f|`。**

### 3.2 「按 IC 符号配权重」的样本内结果会自证

`test_sign_consistent_combo.py` 用**同一批 125 天**既估 IC 又评估，得到 IC **+0.0380**。
这是**用同一份数据拟合权重再在同一份数据上评估** —— 必然偏乐观。
必须以时间切分做样本外检验（§4）。

## 5. 诚实结论

### 5.1 支持改符号的证据

1. **符号在训练期与测试期一致**：训练期 IC +0.0549（t=+2.12），测试期 +0.0261 —— 
   没有出现符号反转。
2. **两期都优于现状**：现状训练期 −0.0449、测试期 −0.0175。
3. **在测试期 65 天里，sign-only 有 55.4% 的天数胜过现状**。
4. **sign-only 与 IC-weighted 样本外几乎相同**（+0.0261 vs +0.0280）
   ⟹ 增益**几乎全部来自符号方向**，而非幅度估计。这降低了过拟合担忧
   （10 个符号参数 vs 10 个连续参数）。

### 5.2 不能过度声称的理由

1. **测试期 t 仅 +0.88 ~ +0.90，未达显著**。
2. **配对差 t 仅 +1.23 ~ +1.25，胜率 55.4%** —— 弱证据。
3. **测试期 65 天是一个连续时段**，不是独立重复；宏观 regime 未变，
   结论**只对 2026-01 ~ 2026-08 这段区间负责**。
4. **样本内 +0.0380 → 样本外 +0.0261/+0.0280，衰减约 30%** ⟹ 存在过拟合成分。
5. `REV_5` 与 `VOLATILITY_20` 是本期唯一稳定显著的因子，
   而它们恰好是「短期反转」与「低波动」这两个**众所周知、且可能已被交易**的效应。

### 5.3 因此

- **不建议**据此直接上线新的权重配置。
- **建议**把「符号方向」列为**待确认假设**，用**更长区间**（需要更多历史数据）
  或**滚动窗口**再验证。
- **可以确定的是**：现状 5 套人工权重在合格池口径下**方向系统性错误**
  （每套的 `Σ(w·IC)/Σ|w|` 全为负：−0.0172 / −0.0338 / −0.0039 / −0.0186 / −0.0139）。

## 6. 可独立验证的结论

1. 原处置表按「IC 为正即方向正确」判断，**忽略负权重因子**，判据应为
   `sign(w_f)×IC_f`（§0.1、§1）。
2. 合格池口径下 **45 个 (策略,因子) 组合中仅 4~6 个达 \|t\|≥2**；
   方向正确的显著组合只有 `REV_5`(正权) 与 `VOLATILITY_20`(负权)（§2）。
3. **5 套现状策略的原样加权 `Σ(w·IC)/Σ|w|` 全为负**
   （−0.0172 / −0.0338 / −0.0039 / −0.0186 / −0.0139）（§1）。
4. `disposition_v2.py` 的「符号全对上限」列**恒等于原样加权**，无信息量（§3.1）。
5. 样本内按 IC 配权得 +0.0380 属**自证**，必须时间切分（§3.2、§4）。
6. **样本外：sign-only 测试期 IC +0.0261（t=+0.88），IC-weighted +0.0280（t=+0.90），
   现状 −0.0175**；配对差 +0.0437（t=+1.23，胜率 55.4%）（§4）。
7. **增益几乎全部来自符号方向**（sign-only ≈ IC-weighted），非幅度（§5.1.4）。
8. **结论未达统计显著，不建议直接上线**（§5.2、§5.3）。
