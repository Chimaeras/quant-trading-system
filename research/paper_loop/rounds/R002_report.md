## 1. 一句话结论

R001 的衰减**不是**数据构造造成的。构成通道（2026-02 供应商批量补录的 1,888 只代码）
在统计上**确实**可检出（|dIC| = 0.0066 > 安慰剂 p95 = 0.0032，且超过 200 次抽样的最大值 0.0051），
但它只能解释 IS→OOS 衰减的 **17.0%**（预注册要求 ≥50% 才算成立）；
退市收益通道更是可以忽略——按 L&R/Shumway 约定补 −30% 后，R001 的 D1 净收益只下降 **0.10bp**，
而 R001 的价差是 **+53.7bp**。
**本轮是干净的负知识：R001 的衰减不能用「数据库构造」解释。**

## 4. H1a 构成通道：统计上可检出，经济上不够

### 4.1 主结果

| 口径 | OOS IC | HAC t | 与全池差 |
|---|---|---|---|
| `U_all` 全池（= R001） | **−0.0215** | −0.70 | — |
| `U_consistent` 构成一致池（3,438 只） | **−0.0281** | −1.01 | dIC_real = **+0.0066** |
| IS（全池，供对比） | −0.0605 | −7.29 | — |

**安慰剂分布**（从 OOS 内在场代码中**随机剔除同为 1,888 只**，独立重复 **200** 次，种子 20260914）：

| 统计量 | 值 |
|---|---|
| \|dIC\| 中位数 | 0.0011 |
| **\|dIC\| p95** | **0.0032** |
| \|dIC\| 最大值 | 0.0051 |
| **\|dIC_real\|** | **0.0066** |

→ **K1（统计判据）通过**：真实构成效应（0.0066）不仅超过 p95（0.0032），
还超过 200 次随机抽样中的**最大值**（0.0051）。构成效应**不是噪声**。

### 4.2 但经济判据不过 → K2 触发

```
batch_explained_share = (IC_OOS(U_consistent) − IC_OOS(U_all)) / (IC_IS(U_all) − IC_OOS(U_all))
                      = (−0.0281 − (−0.0215)) / (−0.0605 − (−0.0215))
                      = +0.170   <  0.50（预注册要求）→ K2 触发
```

**方向解读（必须诚实说明）**：batch 代码自身的反转更弱（见 §5 的 `U_batch-only` IC = −0.0099），
所以把它们放进 OOS 截面会**稀释**反转强度，使全池 OOS IC 从 −0.0281 抬到 −0.0215。
即「剔除 batch 后衰减**更明显**」。**这正是 R001 事后诊断的方向，也是预注册第 2.1 节预先声明的方向**
——本轮**没有**在看到结果后改口。构成效应真实存在，但只能解释衰减的 **17%**，
**不足以支撑 H1a**（H1a 需要 ≥50%）。

### 4.3 阳性对照证明估计量有鉴别力（K4 未触发）

| 口径（OOS） | IC |
|---|---|
| 只含 batch（1,888 只） | **−0.0099** |
| 只含构成一致池（3,438 只） | **−0.0281** |
| \|diff\| | **0.0182** ≫ 阈值 0.002 |

→ 估计量能清楚区分两个**构成差异最大**的池，故 §4.2 的「构成效应小」是**真实的小**，
不是「估计量测不出来」。这是 R001 的 K7 教训的直接修正（见 §8）。

### 4.4 IS 内部对照进一步削弱构成解释

| 项 | 值 |
|---|---|
| 仅 IS-A（2024）有行情的代码 | **43** 只 |
| 仅 IS-B（2025）有行情的代码 | **312** 只 |

| IC（IS-B） | −0.0657 |

IS 内部也发生了构成变化（312 只只在 IS-B 出现），但 IC **没有随之衰减**（反而略强）。
若构成是衰减的主因，IS 内部应同步出现衰减。**不支持 H1a。**

## 5. H1b 退市收益通道：方向对，量级可忽略

R001 把「退出价缺失」的信号**整条丢弃**。按 L&R 引用 Shumway (1997) 的约定，
业绩型退市的缺失收益应按 **−30%** 补，而不是丢弃。本轮照做：

| 项 | 值 |
|---|---|
| 可补 δ 的信号总数（**非机械性**缺失退出） | **2,311** |
| 其中落在 attrited 名字（样本内停止交易，共 99 只）内 | 396 |
| 被排除的**机械性**越界（退出越过面板末尾，所有名字同等受影响） | 16,339 |
| δ = −30% 后 IS D1 净收益 | **+0.5606%**（R001：+0.6584%） |
| **D1 净收益下降** | **+0.10bp**（K3 阈值 5bp；H1b 成立需 ≥26.9bp）→ **K3 触发** |
| 仅对 attrited 名字补 δ | 下降 +0.04bp |
| δ = −24% / −36% | 下降 0.08bp / 0.12bp（单调，K8 未触发） |

**对比 R001 的价差 +53.7bp**：退市收益缺失最多改变 **0.10bp**，占 0.19%。
**该通道在本面板上可忽略。**

### 5.1 P5：方向与假设一致，但样本量太小

| 口径 | attrited 名字占比 |
|---|---|
| D1（输家分位） | **3.43%** |
| D10（赢家分位） | **1.59%** |
| 全池 | **1.78%** |

→ 方向**符合**假设（退市/停止交易的名字确实更集中在输家分位，约为全池的 1.9 倍），
但基数太小（99/5,555 = 1.78%）使得总影响可忽略。
**这是「机制方向成立、量级不足」的典型案例**，也是本轮最有价值的一条负知识。

## 6. 附带发现：2026-02 的 1,888 只是**供应商补录**，不是新股

| 证据 | 值 |
|---|---|
| 首次出现日在 2026-02 的代码数 | 1,888 |
| 占 OOS 截面单元格比例 | **29.9%** |
| 占 IS 截面单元格比例 | **0%** |
| 名单样例 | `300001, 300002, … 300019`（创业板**最早一批**代码段） |

`300001` 等属于创业板 2009 年首批上市代码（**外部常识，非本地证据**），
但它们在本地面板中**最早只出现在 2026-02**，且此前完全没有行情行。
**结论（本地证据支持）**：这不是真实 IPO 潮，而是**供应商一次性补录**——
`market_data` 的历史覆盖在 2026-02 之前对创业板/科创板是不完整的。

这带来两个后果，已记入队列：
1. **研究可用性**：任何跨 2024→2026 的对比都含构成断层（R001 已用事后诊断量化过）；
2. **数据质量**：这是**可修复的入库问题**，不是数据本身不可得 →
   `decision_queue.md` **D-R002-01**（补录历史行情属数据源/入库口径变更，需用户决策）。

## 7. 已知偏差披露（必填）

1. **本轮的检验对象是本地面板自身**，故 R001 的全部偏差披露仍然适用
   （前复权执行价、无 PIT 池、`selector_result` 稀疏、停牌/退市不可观测、样本仅 1.7 年）。
2. **δ 是假设值而非实测值**：本地**没有**退市收益字段，−30% 来自 L&R/Shumway 的约定（美国数据）。
   本轮的结论对此**不敏感**（±20% 只移动 0.02bp），但「δ 取值是否适用于 A 股」**本地无法验证**。
3. **attrited 的判定是「最后一次出现早于面板末尾」**，无法区分「退市」「长期停牌」「供应商数据中断」。
   三者在本地不可分辨——这本身是 B-R001-05 的一部分。
4. **机械性/非机械性的划分**只按「退出索引是否越过面板末尾」。中段缺口（停牌后复牌）
   会被当作非机械性而补 δ，这在语义上可能把「停牌」误当「退市」。
   该取值使 H1b **更容易**成立（补更多负收益），而 H1b 仍失败 →
   结论方向**不受**该宽松划分影响（仅对 attrited 名字补 δ 时下降 0.04bp，同样远低于阈值）。
5. **`U_consistent` 定义含一个自由参数** `MIN_HIST_IS_DAYS=120`，已做 ±20% 敏感性且结论不变。

## 8. 本轮教训（写入下一轮预注册设计）

1. **R001 的 K7 教训被成功修正**：把工具校验条件写成**与被检假设同构**的形式
   （「估计量能否区分两个构成差异最大的池」），K4 这次**没有**误触发（0.0182 ≫ 0.002）。
   R001 的 K2 惰性教训也一并修正：本轮所有判据都先用探针确认**可触发**再写进预注册。
2. **预注册必须区分「统计显著」与「经济足够」**：本轮的构成效应两者结论相反
   （K1 通过、K2 不过）。若只写单一判据，会得出**相反**的结论。
   今后凡涉及「某偏差是否解释了某结果」的假设，**必须同时写统计与经济两条判据**。
3. **parity 断言应成为跨轮复用实验的标配**：本轮 |diff| = 0.000e+00 的精确复现，
   是「两轮结果可比」的前提；否则任何差异都可能是实现差异而非真实差异。
4. **补录批次的发现说明「数据可用性」本身需要被监控**：1,888 只代码在单月内凭空出现，
   会静默改变任何跨期结论。建议在数据层加入**按月的代码覆盖监控**（记入 D-R002-01）。
