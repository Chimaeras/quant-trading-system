## 0. 为什么补这一节，以及结论

目标措辞要求「**分组单调性**」诊断。我此前只有 `D10−D1` 这一个**两端价差**，
从未检验中间分组是否**有序**。补齐后得到一个决定性的否定结论：

> **17 个因子中，0 个呈现单调的十分位收益排序。**
> 不是"弱单调"，而是**连 |单调性| ≥ 0.3 的都没有**（单调性得分全部落在 −0.08 ~ +0.20）。

**含义**：这套打分体系**不只是"平均 IC 弱"，而是"分组结构本身不存在"**。
分数高低与收益之间**没有稳定秩序**，只有两端的噪声。

## 2. 两个「假信号」的解剖（重要）

### 2.1 `LIQUIDITY_20`：单调性 0.20，但 t = 6.94

它的 D10−D1 = **+10.50%**，看似极强，但看逐组：

```
D1=0.22  D2=0.25  D3=0.38  D4=-0.51  D5=-1.44
D6=-4.07 D7=-3.56 D8=-0.64 D9=+2.40  D10=+10.72
```

**前 8 组是负的、中间最深（D6 −4.07），末两组突然正。**
这不是单调关系，而是**「高成交额股票的极端尾部」**。
单调性得分仅 0.20，尽管它的 t 值高达 6.94 →
**说明「单调性得分的稳定性」与「单调性的强弱」是两件事**。

⟹ **`D10−D1` 大 ≠ 因子有效**。`LIQUIDITY_20` 是本次最强的反例。

### 2.2 `VOL_TURNOVER`：D10−D1 = +6.06 但 D9 = −4.50

```
D1=-0.10  D2=0.23  ...  D7=0.68  D8=-0.00  D9=-4.50  D10=+5.95
```

**D9 与 D10 符号相反、跨度 10 个百分点** —— 纯噪声。
这正是我先前在 T+20 稳健性文档里注意到的「顶端单调性被破坏」，
现在在**逐因子层面**得到确认。

### 2.3 几乎所有因子的逐组均值都是正的

注意多数因子的 D1…D10 **全部为正**（`TREND_MA`, `RSI_14`, `VOL_RATIO`, `MAXDD_60` …）。
这反映的是**该区间合格池整体的正漂移**，与因子无关。
因子的信息**只体现在组间差异**上，而那个差异很小（多数 < 0.5pp）。

## 3. 对既有结论的影响

### 3.1 削弱「避开最低分」的用法

我在 T+20 稳健性文档里说过：正价差可靠、正确用法是**「避开最低分」而非「买入最高分」**。
本节的单调性结果**削弱**了这个建议：
若十分位无序，则 **D1 的"最差"同样是端点噪声**，不是稳定的"应避开"信号。

**修正为**：T+20 的 D10−D1 正价差**在统计上成立但结构上不可依赖** ——
它来自两端，而两端在逐组层面都不单调。

### 3.2 强化「改权重无用」的证明

阶段2 定论已证「合成 IC = 因子 IC 的加权平均」（逐日相关 0.98~0.996）。
本节进一步表明：**连分组结构都不存在**。
⟹ 不是"权重配错了"，而是**这些因子在当前口径下没有可提取的排序信息**。

### 3.3 `REV_5` 的单调性同样只有 0.04

这是最值得注意的一点：`REV_5` 是全体系**唯一**通过正向显著性检验的因子
（IC +0.0408, t=+2.26），但它的**单调性得分仅 0.04**。

```
REV_5: D1=0.00 D2=0.36 D3=0.36 D4=0.30 D5=0.33
       D6=0.24 D7=0.34 D8=0.55 D9=0.68 D10=0.62
```

D2…D7 几乎全在 0.24~0.36 之间**平坦**，只有 D8~D10 略微抬高。
⟹ `REV_5` 的 IC 显著性来自**弱而稳定的尾部倾斜**，**不是**一个清晰的分组结构。
这解释了为什么它在阶段4 的组合层回测中扣成本后所剩无几。

## 4. 可独立验证的结论

1. **17 个因子的分组单调性得分全部落在 −0.08 ~ +0.20**，
   无一达到 \|单调性\| ≥ 0.3（§1）。
2. **`LIQUIDITY_20` 是"假信号"典型**：D10−D1 = +10.50%、单调性得分 t = 6.94，
   但逐组为「前 8 组负、中间最深 −4.07、末两组骤正」，单调性仅 0.20（§2.1）。
3. **`VOL_TURNOVER` 的 D9 = −4.50 与 D10 = +5.95 符号相反**，
   证明其 D10−D1 = +6.06 来自两端噪声（§2.2）。
4. **多数因子的 D1…D10 全部为正**，反映合格池整体正漂移，非因子信息（§2.3）。
5. **`REV_5` 单调性仅 0.04**，D2…D7 平坦在 0.24~0.36，
   其 IC 显著性来自**弱而稳定的尾部倾斜**而非清晰分组结构（§3.3）。
6. **「避开最低分」的用法被削弱** —— 无序分组下 D1 同样是端点噪声（§3.1）。
7. **`D10−D1` 大 ≠ 因子有效** —— 必须同时报告单调性得分与逐组均值（§2.1、§2.2）。

## 5. 方法论教训

- **只报 `D10−D1` 会产生假信号**：本次 `LIQUIDITY_20`（+10.50%）、
  `VOL_TURNOVER`（+6.06%）、`VOL_PRICE`（+3.41%）、`MOM_60`（+2.52%）
  都是两端驱动，逐组看毫无秩序。
- **必须同时给三样东西**：逐组均值表、`D10−D1`、单调性得分与其 t。
- **单调性得分的 t 高不代表单调性强**：`LIQUIDITY_20` 的 t = 6.94 但得分仅 0.20 ——
  说明那个微弱的"倾斜"极其稳定，却毫无实用强度。
