## 0. 一句话

本轮把「判据 / 审计器分离」结构从**一个具名语义标签**（R013 的 `monotonicity`）推进到
**两个数组载荷的逐元素数值**——`daily_rank_ic[]`（`trade_date`/`rank_ic`/`sample_size`）与

## 2. 论文摘要级读解（用于判据抽取，**不含**任何数值采纳）

CZ2022 的工作是：把数百个「截面收益预测变量」的**构造代码与数据公开**，并**逐条比较**「本研究复算出的
长空组合 t 统计量」与原论文表格里的 t 统计量，从而给出一个**可被任何人重跑的复算基准**。
论文的核心方法论落在**工程与口径**上：为每个信号**手工采集**原论文的关键表、检验类型、**可预测性方向**、
均值、t 统计量、**个股加权方式、组合分位、再平衡频率**等；把这些**构造规格**落成模块化、可复算的代码；
把「不满足原论文筛选条件的股票-月」**置为 missing**（而不是赋 0，也不删除）；
把**失败的复算与实现偏离**照样留在数据集里；在发现实现错误时**公开修正并重算**。

**本轮只取「做法种类」层面的判据（L 档），不取任何数值、不取任何临界值、不做任何复现。**

### 4.2 与 R012（HXZ2020）的**同源风险**显式披露（防重复研究，协议 §4）

- **R012 已用 HXZ2020**（*Replicating Anomalies*）作判据来源，主题同为「复现」。
- **同源风险真实存在**。**本轮的处置（可核验）**：
  1. **显式排除** HXZ2020 已用过的判据面——**复现率、`|t| ≥ 1.96` / `t ≥ 3` 门槛、`0.64` 之类的量级、
     以及「多数异象不可复制」这一结论：R014 的 J-1…J-7 **均不含**任何复现率或显著性门槛；
  2. 只使用 CZ2022 **独有**的做法种类：**缺失置 missing 而非 0（J-3）**、
     **构造规格逐条记录（J-2）**、**不得静默丢弃 + 偏差归因 + 勘误重算（J-4）**、
     **符号约定显式（J-5）**、**字段定义溯源（J-7）**；J-1/J-6 只作为**术语与可能性边界**使用；
  3. **被审计对象无重叠**：R012 审计的是「**声明性文本字段族**」（`basis_note`/`universe_note`/`note`/
     `metric_scope` 等的真值、覆盖与同义），R014 审计的是「**两个数组载荷的逐元素数值与其计数字段**」。
- **结论**：同源风险**已披露并已处置**；若审阅认为仍构成重复，**按 `D-R014-0x` 登记并回退到
  `INSUFFICIENT_EVIDENCE`**，本轮**不**据此放宽任何判定。

| R009 | **Pearson 侧** IC 族：`pearsonCorrelation` 的守卫量纲（`vx < 1e-18` 破坏尺度不变性）、标量不可定义 vs 真 0 | **不重叠（但相邻，须逐条划界）**：R009 判的是 **Pearson 相关系数的守卫阈值与尺度性**；本轮判的是 **Spearman 侧秩的计算与计数字段**（非有限值进入 **秩** 的排序、`sample_size` 是否等于**有效**观测数）。两者的谓词不同（「阈值/尺度不变性」vs「秩排序/计数忠实」），且本轮**不**重测尺度不变性。 |
| R011 | 承重分叉 `holding_days`/`group_count`/`min_cross_section_size` 的**载荷可恢复性与备选可枚举性** | **部分相邻，本轮显式排除**：R011 已判「`group_count` 在 `F-SNAPSHOT` 缺键」等 ⟹ R014 **不重做**分叉可恢复性；`group_count`/`minCrossSectionSize` 在本轮只作为**±20% 敏感性网格**出现。**另**：「被丢弃的截面日是否有披露」在本轮**只作描述性登记**（正是为避免与 R011 的可恢复性结论重叠）。 |
| R012 | `factor.ts` 各块的**声明性文本字段族**（真值 / 覆盖 / 跨块同义） | **不重叠**：R012 的对象是**文本字段**与块覆盖；R014 的对象是**数值字段与计数字段**。**边界**：若某个数值字段**没有任何单位/口径声明**，R014 的判定词是 `UNIT_UNDECLARED`（**数值不可复算**这一后果），**不**复用 R012 的「声明文本是否为真」子句。 |
| R013 | `monotonicity` **标签**：名实 / 非退化 / 可重建 / 不越界 | **不重叠（主体不同）**：R013 审计的是**由组均值导出的标签**；R014 审计的是**组均值与日 IC 这两个数值本身**（以及它们的计数字段）。**必须显式披露的交互**：R013 的 `V18 = TRUE_CLAIM`（披露粒度含「组数 + 每组样本量」）判定的是**字段存在性**；R014 将独立检验该字段的**单位**是否为「每组样本量」（结论若不同，**只登记** `D-R014-0x` 并在报告中把 R013 的读法**限定为「字段存在」**，**不**回写 `R013_prereg.md` / `R013_report.md` 的冻结与已发布文本）。 |

**结论**：无维度重复。R014 的**新维度** = 「**数组载荷的逐元素数值与其计数字段**的忠实性」。

## 6. 被审计对象与 H0（四子句）

**被审计对象**：项目在**因子研究（snapshot / 统一报告）**与**评分回测（DTO）**两条面上产出的
**两个数组载荷**：
- `daily_rank_ic[]`：`trade_date` / `rank_ic` / `sample_size`；
- `grouped_returns[]`：`group_no` / `label` / `avg_return` / `observations`；
及其**生产者**（`FactorResearchEngine.groupedAverageReturns` / `summarize`）、**映射面**
（`FactorResearchService.dailyIcList` / `groupedReturnList`、`ScoringBacktestService.toFactorAnalysisDto`）
与**展示面**（`FactorResearch.vue`、`ScoringBacktest.vue` 的列标签与提示文案）。

**H0（被杀死即为「载荷数值忠实性假设不成立」）**：

> **H0** = 这两个数组载荷的**逐元素数值**同时满足四条：
> **(i) 可重建**：每个元素的数值可由「**载荷自带的构造规格** + 同一输入**多重集**」**唯一重算**
> 到声明精度（含并列秩规则与分组边界规则）——**不得**依赖未声明的输入**行序**或未披露的中间变换；
> **(ii) 单位忠实**：计数字段（`sample_size` / `observations`）的单位在**实现 / 声明 / 展示**三处一致，
> 且**同名字段**在不同生产路径与不同面上**同义**；
> **(iii) 同量同值**：**同一个量**（日 rank IC / 组平均收益 / 计数）在**不同发射面**上数值一致；
> 取整/精度规则**一致**或在载荷中**显式声明**；
> **(iv) 计数忠实**：计数字段必须等于**实际参与该数值计算的有效观测数**——**不得**把非有限值或
> 未通过口径的行计入有效观测，**不得**让被排除的观测以**看不出差别**的方式消失。

**边界声明（先写死）**：
1. 本轮**不**评估这两个数组数值的**统计性质**（不判显著性、不判区间质量、不判因子有效性）；
2. 本轮**不**评估 `rank_ic_mean`/`rank_ic_ir`/`pearson_ic_mean` 等**标量**字段（属 R006/R007/R009）；
3. `(iii)` 的判定**只**在不同面**都能产出该量**时成立；**某一面不携带该数组**只作**描述性登记**，
   **不**参与 `K3`（避免与 R011/R012 的覆盖类结论重叠）。
