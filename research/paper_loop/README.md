# research/paper_loop — 论文驱动循环状态目录

本目录是「论文驱动量化研究与工程迭代」长期目标的**唯一状态真相源**。

## 目录职责

| 路径 | 内容 |
|---|---|
| `progress.md` | 当前轮次、当前任务、计数、下一轮任务（每轮更新） |
| `stage_summary_R001_R010.md` | **每 10 轮**的阶段性研究总结（采纳/拒绝/阻塞汇总 + 重复研究与方向漂移检查 + 枯竭门槛评估）。这是本目录下**第一份**检查点文档：**R005 的 5 轮检查点未生成独立文件**（缺口见该文件 §6 第 1 行，如实记录、不补造） |
| `stage_summary_R011_R015.md` | **R011–R015 的 5 轮检查点**（5 轮节点 = R005 / R015），**同时是收工检查点**。结构对齐上一份（§0–§9），另含**收工结论**（`STOPPED_BY_USER`）与 R005 缺文件缺口的**重申**。**只汇总、不新增判定** |
| `paper_ledger.csv` | 论文台账（机器台账，每篇论文一行，**含被拒绝的**） |
| `preregistration_template.md` | 立项预注册模板；每轮复制为 `rounds/Rxxx_prereg.md`。**§10 仪器合格标准**（`CLN`/`INJ` 的语义与通过判据、测量方法合格标准、事后修改的处置）与杀死条件**同等冻结**：必须在**看到结果之前**写死，否则本轮结论无效（依据 `D-R011-03` 裁定，2026-09-15） |

| `decision_queue.md` | PENDING_USER 事项（**不阻塞整个循环**） |

| `rounds/` | 每轮记录：`Rxxx_review.md`（审查）、`Rxxx_prereg.md`（预注册）、`Rxxx_report.md`（报告） |
| `experiments/` | 隔离实验目录，每实验一子目录 |
| `baselines/` | 基线定义与实测结果（必须同口径、含成本） |
| `decisions/` | 决策归档。现有：`round_closeout_R001_R015.md`（2026-09-14 用户裁定 Q1「按 P0 全量排队一次做完」/ Q2「允许加字段，不改既有键语义」后，对 85 项 `PENDING_USER` 的**逐项处置**：已落地 / 已满足 / record-only / 需裁定 / 阻断 / **未执行**的 DDL 草案与回滚） |

## 不可违背的四条

1. **机器台账是 `paper_ledger.csv`**，不要另建第二份台账。人工可读的汇总在每 5/10 轮检查点生成，不改写 CSV
   （检查点文件命名 `stage_summary_Rxxx_Ryyy.md`，并在本表登记）。
2. **预注册先于代码**。`rounds/Rxxx_prereg.md` 未落盘前，不得写任何实验或生产代码。
3. **杀死条件一经写下不得事后放宽**。放宽即视为本轮结论无效。
4. **论文被拒绝必须归档**（含失败原因分类）。"某类方法在 A 股无效"是本循环的主要产出形式之一。

## 与主协议的关系

- 仓库范围、红线、验证命令、口径：沿用 `docs/Codex量化系统持续优化执行协议.md` 与 `docs/研究口径规范.md`。
- 本循环在提交策略上**例外**：每轮通过验证即 commit + push（研究轮次相互独立，不做批次合并）。
- 循环**不设固定轮次上限**，只在提示词列出的终止条件下结束。
